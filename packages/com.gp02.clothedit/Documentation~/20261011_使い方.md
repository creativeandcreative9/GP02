# GP02 布の編集 使い方

GP02 は、Unity の上で衣装（布）を**つまんで引っ張る**だけで、布として自然に形が決まるメッシュ編集ツールです。
布は 1cm 間隔の粒子として計算するので、**引っ張っても布が伸びず、体や内側の布にすり抜けません**。
できあがった形は、**シェイプキー（BlendShape）**として保存します。

英語版は `20261011_Manual_en.md` です。ウィンドウ上部の「説明書」ボタンからも、言語に合わせて開けます。

画面は、主な操作だけを出す**かんたん表示**（既定。はじめての方向け）と、すべての機能と設定を出す**くわしく表示**を、ウィンドウの一番上の「かんたん／くわしく」で切り替えられます（機能は減らず、見せ方が変わるだけです。詳しくは「2-5」）。
この説明書では、くわしく表示でだけ出る項目に「（くわしく）」と書いています。

## 1. インストール

### 必要なもの
- Unity 2022.3 以降（動作確認は 2022.3.22f1）
- VRChat SDK や NDMF は**要りません**。素の Unity で、すべての機能が動きます

### BOOTH で配布している .unitypackage から入れる
1. Unity でアバターのプロジェクトを開く
2. ダウンロードした `.unitypackage` をプロジェクトの Project ウィンドウへドラッグ＆ドロップする（または **Assets → Import Package → Custom Package**）
3. 取り込む一覧がすべてチェックされていることを確認して「Import」を押す
4. コンソールに赤いエラーが出ていなければ完了。メニューに **Tools → GP02** が増えます

### 速くする（任意）
**Burst**（Unity の高速化パッケージ）が入っていると、大きな衣装でもなめらかに動きます。
Burst が入っていないと、**初めて布の編集ウィンドウを開いたときに1回だけ**、ウィンドウの上に案内の帯が出ます。**［入れる］**を押すと入ります（**［今はしない］**で閉じると、もう出ません）。
あとからでも、ウィンドウの上の「くわしく」に切り替えて、「詳細設定」の **Burst を入れる** ボタン（Burst が無いときだけ出ます）か、Package Manager で「Burst」(`com.unity.burst`) から入れられます。入れなくても、すべての機能は使えます。ただし重ね着や大きな衣装では、手を離したあとの仕上げが時間切れになって伸びが残りやすいので、入れるのがおすすめです。
ウィンドウの一番下の状態の1行の「高速化」が「Burst」になっていれば効いています（詳しい状態は、その行にマウスを乗せると出ます）。

### 説明書について
この説明書は、パッケージの `Documentation~` フォルダに入っています。`~` が付いたフォルダは Unity に読み込まれないので、
.unitypackage で入れた場合は、配布物の `Documentation~` フォルダから直接開いてください。

## 2. はじめての編集（テスト用の衣装で）

まずは、付属のテスト用の衣装で一通り試すのがおすすめです。

### 2-1. テスト用の衣装を作る
メニュー **Tools → GP02 → テスト用の衣装を作る**
- シーンに `GP02_TestCloth` ができ、スカートが選ばれた状態になります
- ボーン付きの簡単な体（高さ 1.4m）と、ペチコート・リボン付きのスカートです

### 2-2. 編集を始める
**いちばん簡単な方法**: Hierarchy で衣装を**右クリック → GP02 で布を編集**。ウィンドウが開いて、すぐ編集が始まります（複数の衣装を選んでいれば、重ね着としてまとめて編集します）。

ウィンドウから始めるとき:
1. メニュー **Tools → GP02 → 布の編集** でウィンドウを開く
2. Hierarchy で衣装を選ぶ（編集していないときは、選ぶだけで「対象」に入ります。「選択中のオブジェクトから設定」でも入れられます）
3. 大きな「編集を開始」を押す
4. 数秒で準備が終わります。シーンビューの左上に、操作の案内（1行）と小さな札（3つの操作）が出て、右側に GP02 の道具バーが出ます（3章）

**アバター全体など、衣装ではないものを選んだとき**は、警告のダイアログは出ません。「対象」の区切りに「**この中の衣装**」の一覧が出るので、編集する衣装のボタンを押してください（その衣装が「対象」に入ります）。体のメッシュらしいもの（名前に Body・体・Face・顔 などが付くもの、表情のシェイプキーが多いもの）は、一覧の最後に「体のようです」と出ます。右クリックの「GP02 で布を編集」や「選択中のオブジェクトから設定」でも、同じ一覧が出ます。
体のメッシュを対象にしたときも、編集は始められます。ただし「診断」に「「Body」は体のメッシュのようです。服を編集するときは、服のオブジェクトを選んでください」と出て、その下に衣装の候補のボタンが並びます。

編集を始める前のウィンドウには、「はじめての方へ」の手順と「対象」と「編集を開始」だけが出ます（道具・ブラシ・対称・保存などは、編集を始めてから出ます）。手順は、今どこまで済んだかが印で分かります。編集中に手順の欄を畳んでいるときは、見出しの下に「次: 3. 動かさない所をピン留め」のように、次にやることが1行で出ます（押すと手順の欄が開きます）。すべて済むと「✓ 手順はすべて済みました」と出ます。

| 手順 | やること |
|---|---|
| 1. 衣装を選ぶ | Hierarchy で衣装のオブジェクトを選ぶ（自動で「対象」に入る） |
| 2. 編集を開始 | 「編集を開始」を押す |
| 3. 動かさない所をピン留め（任意） | 「服の付け根（ウエスト・首まわりなど）を自動でピン留め」を押す。または **P** キーで塗る |
| 4. つまんで引く | **W** キーで布をドラッグ |
| 5. シェイプキーとして保存 | ウィンドウの上の「保存」を押す（名前は「保存」の区切りで決められます） |

### 2-3. ピン留め → つまむ → 保存
1. ウィンドウの「**服の付け根（ウエスト・首まわりなど）を自動でピン留め**」を押すと、ウエストのまわりが一周まとめて留まります（「ピン留めしました（N 点）」と出ます）。手で留めるときは、シーンビューにマウスを乗せて **P** を押し、ウエストのあたりを塗ります。留めた所には**青い点**が出ます（ここは動かなくなります）
2. **W** を押し、スカートの裾をつまんで外へ引きます。手を離すと、少しのあいだ形が落ち着く動きをして止まります
3. 気に入らなければ **Ctrl+Z** で戻します
4. ウィンドウの上の「**保存**」を押します（名前を変えたいときは、「保存」の区切りで決めて「シェイプキーとして保存」を押します）
5. `Assets/GP02/Meshes/` にメッシュができ、スカートに新しいシェイプキー（重み 100）として入ります。Inspector で重みを 0〜100 に動かすと、元の形と編集した形の間で変わります

保存したあとも、続けて編集できます。もう一度保存すると 2 つ目のシェイプキーが入ります。

### 2-4. 終わるとき
「編集を終了」を押します。**保存していない編集**（形を変えたまま、まだ保存していない）があるときは、先に確認が出ます。

| 選ぶもの | 結果 |
|---|---|
| 保存する | シェイプキーとして保存してから、編集を終える |
| 保存しないで終わる | 編集の内容を捨てて終える |
| やめる | 編集を続ける |

別の衣装に切り替えるとき（右クリックやウィンドウで別の衣装を始めるとき、シェイプキーの一覧の「布で編集する」で別の衣装を始めるとき）も、同じ確認が出ます。
形を変えていなければ（ピンや選んだ点だけなら）、確認なしで終わります。
テスト用の衣装はシーンから消して構いません。

### 2-5. かんたん表示とくわしく表示
ウィンドウの一番上の「かんたん／くわしく」で切り替えます（選んだほうを覚えています。シェイプキーの一覧のウィンドウも同じ切り替えです）。

**かんたん表示**（既定）で出るもの:
- 編集の前: 手順・対象・大きな「編集を開始」（診断は、重大・注意があるときだけ）
- 編集中: 道具（つまむ・選んで動かす・ピン留め・元に戻すブラシ）、1つ戻す・やり直す、ブラシ半径、対称のオン・オフと「左右の中心を自動で合わせる」、選んで動かすの主な項目（ハンドルの種類・布として／形だけ・なめらかさ）、保存と保存したシェイプキーの一覧（いま体に反映されているかの表示つき）、ウィンドウの一番下の状態の1行（「伸び: ほぼ無し／少し／大きい」）
- シェイプキーの一覧: 有効・名前・重み・複製・削除・左右に分割・左右反転・メッシュに書き出す

**くわしく表示**では、機能と設定がすべて出ます。回す・拡大縮小のボタン、影響範囲・減衰カーブ、対称の軸と中心、表示の区切り、選んだ点の細かい設定と数値で動かす、詳細設定、診断のすべて、シェイプキーの一覧の検索・合成・取り込み・バックアップなどです。
**E**（回す）と **R**（拡大縮小）のキーは、かんたん表示でも使えます。

ウィンドウの一番下の1行には、かんたん表示では「点 6,269 ・ ピン 0 ・ **伸び: ほぼ無し** ・ 高速化 Burst ・ 待機中」のように出ます。伸びは、**ほぼ無し（緑）／少し（黄）／大きい（赤）**の3段階の言葉で、境目は「伸びのヒートマップ」と同じです（5% 未満・15% 未満・それ以上）。数値は、行にマウスを乗せると出ます。くわしく表示では、数値で出ます（粒子の数・ピンの数・最大の伸び・高速化・状態）。診断の「情報」は1行に畳んであり、押すと開きます。

操作の結果は、ウィンドウの真ん中に**短い通知**で出て、すぐ消えます。詳しい内容は、編集中の見出し（「編集中: …」の行）の下の「**結果の欄**」に残ります（右の「×」で閉じられます。2分たつと消えます）。

### 2-6. 編集が消えないしくみ（前回の編集を戻す）
保存していない編集が、うっかり消えないようにしています。
- スクリプトのコンパイル（コードの変更）・プレイモードに入る・ウィンドウを閉じる、のときに、編集中の状態（引いた形・ピン・選んだ点）を、プロジェクトの `Library/GP02/` に自動で取っておきます
- 同じ衣装を対象にすると、ウィンドウの上に「**前回の編集が残っています**（衣装の名前・何分前）」の帯が出ます。**［戻す］**で編集を始めて、形・ピン・選んだ点を戻します（**Ctrl+Z** で、戻す前の形に戻れます）。**［捨てる］**で、取っておいたものを消します
- 衣装を動かした・別のメッシュに替えたなど、同じ状態に戻せないときは、戻さずに理由を帯に出します（取っておいたものは残ります）
- 保存したとき、保存しないで終わると決めたときは、取っておいたものを消します。7日より古いものも自動で消えます
- 取っておくのは、保存していない形・ピン・選んだ点があるときだけです

## 3. 道具とショートカットの一覧

シーンビューにマウスを乗せた状態で押します。右クリックを押しながらの視点移動（W/E など）や、編集中でないときは、Unity 標準の動きのままです。

キーは Unity の Shortcut Manager に「GP02」として登録してあり、**Edit → Shortcuts** の「GP02」で変えられます（変えたキーは、ウィンドウの道具の表示にも出ます）。
編集中だけ有効で、そのあいだは Unity 標準の W/E/R/Q/F などより優先されます。

### 道具
| 道具 | キー | 使い方 |
|---|---|---|
| つまむ | **W** | 布をドラッグして引っ張る。周りの布は伸びずに付いてくる |
| 回す | **E** | 布をクリックして横にドラッグ。クリックした点を中心に回る（**Ctrl** で 15° 刻み） |
| 拡大縮小 | **R** | 布をクリックして横にドラッグ。クリックした点を中心に 0.2〜3 倍 |
| ピン留め | **P** | 塗った所を固定する。**Ctrl+ドラッグ**で外す、**Shift+ドラッグ**で四角く囲む、**ダブルクリック**で部品ごと（**Ctrl** で外す）。ウエストなどは「服の付け根（ウエスト・首まわりなど）を自動でピン留め」でも留められる。詳しくは「6. ピン留め」 |
| ピン留め＋外す | **Shift+P** | 「塗ると外す」をオンにしたピン留め（昔の「ピン解除」）。ドラッグで外し、**Ctrl+ドラッグ**で留める |
| 元に戻すブラシ | **T** | 塗った所を元の形へ近づける（強さはブラシの設定） |
| 選んで動かす | **Q** | 点を塗って選び、ハンドルで動かす・回す・拡大縮小する。もう一度 **Q** で直前の道具に戻る。詳しくは「7. 選んで動かす」 |

「選んで動かす」の間は、**W / E / R** は道具ではなく**ハンドルの種類**（移動・回転・拡大縮小）を切り替えます。P・Shift+P・T は、いつでも道具を切り替えます。
かんたん表示では、ウィンドウと道具バーに「回す」「拡大縮小」のボタンを出しません（くわしく表示で出ます）。**E**・**R** のキーは、どちらの表示でも使えます。

### そのほかのキー
| 操作 | 内容 |
|---|---|
| **Shift**+ドラッグ | 動きを 1/5 にする（精密操作） |
| **Ctrl**+ホイール、`[` `]` | ブラシ半径を変える |
| **Ctrl+Shift**+ホイール、**Shift**+`[` `]` | 影響範囲を変える |
| **F** → マウスを横に動かす | ブラシ半径を変える（「選んで動かす」の間は、なめらかさの半径）。変えている間は円と数値が出る。**クリック**か **F** で確定、**Esc** か**右クリック**で元に戻す |
| **Shift+F** → マウスを横に動かす | 影響範囲を変える（確定・取り消しは F と同じ） |
| **Shift**+右クリック | 布の上に **3D カーソル**を置く（「選んで動かす」の中心を「3D カーソル」にしたとき、回転・拡大縮小の中心になる） |
| **C**（押している間） | 元の形を見せる |
| **Esc** | ドラッグ中・仕上げ中の操作を取り消す（何もしていなければ、選んだ点を解除） |
| **Ctrl+Z** / **Ctrl+Y** | 1操作ずつ戻す・やり直す |
| **Alt**+ドラッグ | 視点を動かす |
| **F1** | すべての操作の一覧を出す・隠す（一覧の右上の「×」でも閉じられます） |
| ピン留めの **Ctrl**+ドラッグ | 塗った所のピンを外す（「塗ると外す」がオンなら、留める） |
| ピン留めの **Shift**+ドラッグ／**Ctrl+Shift**+ドラッグ | 画面上で四角く囲んだ中をまとめてピン留め／解除 |
| ピン留めの ダブルクリック | クリックした部品（島）全体をピン留め（**Ctrl** で解除） |
| 選んで動かすの ドラッグ／**Ctrl**+ドラッグ | 塗って選ぶ／塗って外す |
| 選んで動かすの **Shift**+ドラッグ／**Ctrl+Shift**+ドラッグ | 四角く囲んで選ぶ／外す |
| 選んで動かすの ダブルクリック | 部品（島）ごと選ぶ（**Ctrl** で外す） |
| 選んで動かすで 何もない所をクリック | 選択を解除 |
| 選んで動かすの ハンドルのドラッグ | 選んだ点を動かす（**Shift** でゆっくり、**Ctrl** で刻み） |

### シーンビューの案内（左上）
編集中、シーンビューの左上に、暗い札が出ます（地面や布が何色でも読めるよう、背景は暗い色（ほぼ黒）で、文字は白です）。
- **操作の案内**（1行）: 今の道具の一番大事な操作と「F1: 操作の一覧」だけが出ます（例:「つまむ (W): 布をドラッグして動かす　F1: 操作の一覧」）。「選んで動かす」だけは、点を選ぶ操作と動かす操作の2行です。細かい操作は **F1** の一覧で見られます
- **小さな札**: はじめて使う人のために、まず覚える3つの操作（ドラッグ: 布をつまむ／Alt+ドラッグ: 視点を回す／Ctrl+Z: 1つ戻す）と、「F1: すべての操作」が出ます。右上の「**×**」を押すと閉じて、**もう出ません**。「×」はシーンビューの上のボタンなので、押しても布はつまみません
- **すべての操作の一覧**: **F1**（または、道具バーの「ショートカット」、ウィンドウの「?」）で出し入れします。編集を始めても自動では出ません。一覧にも右上に「×」があります
- 布の長さで届かない所まで引いたときは、橙の線と1行の案内が出ます（次の項）

編集中は、Unity 標準の移動・回転・拡大縮小のハンドル（Hierarchy で選んだオブジェクトの矢印や輪）を**隠します**。GP02 の点や道具のハンドルと重なって、どれが何か分かりにくくなるためです。編集を終えると、元の表示に戻ります（ウィンドウを閉じたとき・プレイモードに入るとき・スクリプトをコンパイルするときも戻ります）。

### シーンビューの道具バー
編集中だけ、シーンビューの右側に「GP02」の道具バーが出ます。
- 道具の切り替えです（ウィンドウの「道具」と同じ）。かんたん表示では、つまむ・選んで動かす・ピン留め・元に戻すブラシの4つ、くわしく表示では回す・拡大縮小も出ます。「選んで動かす」の間は、ハンドルの種類（移動・回転・拡大縮小）の切り替えが、ピン留めの間は「塗ると外す」が出ます
- 「対称」は、オン・オフです。「伸びの表示」「元の形」は、くわしく表示で出ます
- 「ショートカット」は一覧の出し入れ、「説明書」はこの文書を開きます

ウィンドウと同じ設定を変えるので、どちらで変えても同じになります。

### 布の長さが足りないとき（届かない表示）
「つまむ」と「選んで動かす」（布として動かす）で、布の長さで届かない所まで引くと、布は伸びずに手前で止まります。そのとき、シーンビューに**引いている先と、止まった点を結ぶ橙の線**と、「布の長さが足りず、ここで止まりました。選んで動かす（Q）の『形だけ動かす』なら届きます」の一言が出ます（止まった点との差が 1cm 以上、かつ引いた量の 2 割以上のとき。ほんの一瞬の遅れでは出ません）。
- 引きたい量が大きいときは、「選んで動かす」の動かし方を**形だけ動かす**にします（布が伸びることがあります）
- くわしく表示では、案内に「詳細設定の『伸びやすさ』を上げると届きます」も付きます。「伸びやすさ」（くわしく表示の「詳細設定」）を上げても、届くようになります

### ウィンドウの上部
「かんたん／くわしく」で画面の見せ方を、「日本語／English」で言語を切り替えます。「説明書」でこの文書、「?」でショートカット一覧（すべての操作）を開きます。
各ボタンやスライダーは、マウスを乗せると説明（ツールチップ）が出ます。

### 診断
編集を始める前と編集中の問題を、「診断」にまとめて出します。かんたん表示では、**重大・注意があるときだけ**出ます（情報は、1行に畳んであり、押すと開きます）。くわしく表示では、見出しに件数（重大・注意・情報）が出て、「問題なし」の表示や「点検し直す」も出ます。
直せるものには「直す: …」のボタンが付きます。「点検し直す」（くわしく）で、今の状態でもう一度調べます。

| 重さ | 内容 | 直す |
|---|---|---|
| 重大 | メッシュ・面が無い（編集を始められない）／プレハブのアセットそのもの／ボーンが欠けている | — |
| 注意 | Read/Write が無効 | Read/Write を有効にする |
| 注意 | スケールが負（裏返し） | — |
| 注意 | シェイプキーの重みが 0 でない（今の重みの形が差分の基準になる。GP02 で保存したシェイプキーは数えません。編集を始める前の点検だけで出ます） | 重みを 0 にする（編集を終えてから） |
| 注意 | 頂点が非常に多い | — |
| 注意 | 対称がオンで、相手のいない点が 20% を超える（編集中） | 左右の中心を自動で合わせる |
| 注意 | 対象が体のメッシュのよう（名前に Body・体・Face・顔 などが付く、または表情のシェイプキーが多い）。編集の前だけ。編集は止めません | 衣装の候補のボタン（押すと、その衣装が対象になる） |
| 情報 | スケールが軸ごとに違う／同じメッシュをほかのオブジェクトも使っている／MeshFilter のメッシュ／頂点が多い | — |
| 情報 | Burst が無い | Burst を入れる |
| 情報 | ピンが1つも無い（布全体が動きやすい。編集中） | 服の付け根（ウエスト・首まわりなど）を自動でピン留め |
| 注意 | 体が布を突き抜けている（編集中。操作のたびに自動で調べ直す。か所と深さが出る） | 「貫通を直す」（12 章） |

## 4. ブラシの設定

ウィンドウの「ブラシ」の区切りで決めます。かんたん表示では、ブラシ半径だけが出ます。それ以外は「くわしく」で出ます。

| 設定 | 内容 |
|---|---|
| ブラシ半径（cm） | つまむ範囲の半径。**Ctrl+ホイール**か `[` `]` でも変えられる |
| 影響範囲（cm） | つまんだ動きが周りへ広がる範囲。**Ctrl+Shift+ホイール**か **Shift**+`[` `]` |
| 減衰カーブ | 範囲の中心から端へ、動きがどう弱まるか。プリセット（一定・なめらか・直線・鋭い・球）か、自由に描く |
| 距離の測り方 | 「メッシュに沿う」はつながった布だけ、「直線」は近くにあるものを層に関係なく範囲にする（重ね着の内側の布も一緒に動かしたいとき） |
| つながりの許容距離 ε（cm） | 「メッシュに沿う」のとき、この距離以内にある**別の部品（島）**にも範囲を広げる。袖とフリルのように分かれたパーツを一緒に動かせる（0〜5cm、既定 0）。布の計算のつながりは変わらず、範囲の決め方だけが変わる。重ね着の層どうしも、この距離より近ければつながる。選んで動かすの「なめらかさ」の範囲と、元に戻すブラシにも効く |
| 元に戻すブラシの強さ | 1回塗るごとに元の形へ近づける割合（1 で完全に戻る） |

「道具」の区切り（くわしく）では、つまむときの**動かす向き**（自由・面の法線・X/Y/Z 軸・**視線**）と、回すときの**回転軸**（視線・面の法線）も選べます。
「視線に沿って」は、画面の奥・手前の向きだけに動かします（上へドラッグで奥へ、下へで手前へ）。

### 自分のカーブを保存する
減衰カーブの下の「カーブの名前」に名前を入れて「保存」を押すと、今のカーブを保存します（10 個まで。同じ名前は上書き）。
「保存したカーブ」で選んで「呼び出す」と、そのカーブになります。「削除」で一覧から消します。保存先は Unity の EditorPrefs なので、ほかのプロジェクトでも使えます。

### ブラシを当てる前の表示
マウスを布に乗せると、範囲に入る粒子が点で出ます。**中心ほど黄色く濃く、端ほど青く薄い**です（重みの大きさ）。
ドラッグ中も、つまんだ範囲の粒子が同じ色で出続けます。対称がオンなら、鏡像の側にも出ます。
点が多いときは間引いて表示します（最大 1500 個）。「表示」の区切りの「範囲を色で表示」でオフにできます。
「減り方を同心円で表示」をオンにすると、ブラシの円の中に、動きの強さが **75% / 50% / 25%** になる位置を同心円で出します（減衰カーブの形が分かります。一定のカーブでは円の縁と重なります）。

### 伸びの見える化・元の形との比較
- 「伸びのヒートマップ」をオンにすると、布の伸びを緑→黄→赤の点で出します（0% → 5% → 15%）。ウィンドウの「最大の伸び」には数値が出ます
- 「元の形を表示」か **C** キーで、編集前の形を見られます。「見せる形（%）」で、元の形と編集中の形の中間も見られます
- 「元の形を重ねて表示」をオンにすると、編集前の形を**半透明の水色**で重ねます。編集中の形と同時に見えるので、どこがどれだけ出たか・へこんだかが分かります
- 「動いた量のヒートマップ」をオンにすると、元の形からの移動距離を青→黄→赤の点で出します（0 → 2.5cm → 5cm 以上）。動かしたくない所が動いていないかを確かめられます

## 5. 対称（左右対称の編集）

「対称」の区切りで「対称編集」をオンにすると、つまむ・回す・拡大縮小・ピン留め・元に戻すブラシが、**反対側にも鏡に映したように**働きます。シーンビューの道具バーの「対称」でも、オン・オフできます。
かんたん表示では、「対称編集」のオン・オフと「左右の中心を自動で合わせる」だけが出ます。軸・中心のずれ・許容距離・相手のいない点・左右差・左右対称にする、は「くわしく」で出ます。

- **軸**: 鏡になる面に垂直な軸（左右対称なら X）。アバターのローカル座標です
- **中心のずれ**: アバターの中心から、左右の中心（鏡の面）までのずれ（cm）
- **鏡像を探す許容距離**: 鏡に映した位置から、この距離以内の点を反対側の相手にします（既定 2cm）。左右で形が少し違う衣装では広げます
- **基準**: Animator のある親（アバター）を基準にします。見つからないときは一番上の親になります

### 左右の中心を自動で合わせる
衣装がアバターの中心からずれていると、反対側の相手が見つからず、片側しか動きません。
「左右の中心を自動で合わせる」を押すと、元の形を鏡に映したとき一番よく重なる位置を探して「中心のずれ」に入れます（編集中に使えます。対称がオフでも使えます）。
片側だけにある飾りがあっても、残りの部分の対称の面に合います。

### 相手のいない点
対称がオンのとき、反対側の相手が見つからない点を**赤紫の点**で出し、ウィンドウに数と割合を出します（「相手のいない点を表示」でオフにできます）。
そこをつまんでも反対側は動きません。多いときは、左右の中心を自動で合わせるか、許容距離を広げてください。

### 今の形を左右対称にする
「基準にする側」（+X 側か −X 側）の変形（元の形からの移動）を、鏡に映して反対側へ写し、そのあと仕上げで伸びを直します。
中央は両側の平均にします。ピン留めした点と相手のいない点は動きません。**Ctrl+Z** の 1 回で戻せます。
片側だけ編集してから写す、左右で少しずれてしまった編集をそろえる、といった使い方ができます（X 軸では +X がアバターの右側です）。

### 左右差の色分け
「左右差を色分け」をオンにすると、点ごとに、反対側の相手との変形の差（鏡に映した動きとの差）を緑→黄→赤で出します（0 → 0.5cm → 2cm）。ウィンドウには最大の差が出ます。

条件:
- 中央線の近くをつまんだときは、左右が崩れないよう、鏡の面に沿う動きだけになります

シーンビューには、左右の中心（鏡の面）が半透明の四角で出ます。ブラシの円は鏡像の側にも出ます。

## 6. ピン留め（動かさない所を決める）

ピン留めした所は、ほかを引っ張っても動きません。ウエストなどを先に留めてから引くのがおすすめです。ピンの点は、シーンビューに**青い点**で出ます（選んだ点の橙、ブラシの範囲の点、体の貫通の赤い点と見分けられる色です）。

ピン留めは**1つの道具**です。操作は「選んで動かす」と同じ決まりで、キーで留める・外すを切り替えます。

| 操作 | 内容 |
|---|---|
| ドラッグ | 塗って**留める**。塗る範囲はブラシ半径 |
| **Ctrl**+ドラッグ | 塗って**外す** |
| **Shift**+ドラッグ | 四角く囲んで留める |
| **Ctrl+Shift**+ドラッグ | 四角く囲んで外す |
| **ダブルクリック** | クリックした部品（島）全体を留める（**Ctrl** で外す） |

### 服の付け根を自動でピン留め
スカートのウエスト、上着の首まわり、袖の肩の側のような**服の付け根**は、ボタン1つで一周まとめてピン留めできます。ウィンドウの「**服の付け根（ウエスト・首まわりなど）を自動でピン留め**」を押します。このボタンは、手順の3番目（「次: 3. 動かさない所をピン留め」の下）・ピン留めの道具の欄・診断の「ピンが1つも無い」の行に出ます。
- 部品（つながった1枚の布）ごとに、メッシュの**開いた縁**（三角形が1つしか付いていない縁）の輪のうち、**高い所にあって、アバターの縦の軸に近いもの**を付け根として選び、その線から 2cm 以内の点を留めます（スカートなら、ウエストの縁です。足が2本あるタイツは、足首ではなくウエストです。腕を下ろした袖のように両端が同じ高さのときは、軸に近い肩の側です）
- 縁の無い、閉じた形の部品（丸い飾りなど）は、何も留めません。付け根が見つからないときは「付け根が見つかりません」と出るので、手でピン留めしてください
- 今のピンは消えません（足されます）。「ピン留めしました（N 点）」と出て、**Ctrl+Z の 1 回**で戻せます
- 高さの向きと縦の軸は、アバター（Animator の付いた親）から決めます。アバターが無いときは、世界の上向きと、衣装の中心を使います
- 思った所と違うときは、**Ctrl+Z** で戻して、手で留めてください

### 塗る
**P**（ピン留め）で、ドラッグして塗ります。塗る範囲はブラシ半径です。**Ctrl を押しながら**塗ると、ピンを外します。

### 「塗ると外す」（マウスだけで外したいとき）
道具の「塗ると外す」をオンにする（または **Shift+P** を押す）と、操作が逆になります。ドラッグでピンを外し、**Ctrl+ドラッグ**で留めます（四角で囲む・ダブルクリックも同じ）。シーンビューの道具バーにも、ピン留めの間は「塗ると外す」が出ます。
昔の「ピン解除」の道具は、この「塗ると外す」をオンにしたピン留めとして働きます（保存してあった設定も、そのように読み替えます）。

### 四角で囲んで一度に（Shift+ドラッグ）
**Shift を押しながらドラッグ**すると、画面上に四角が出ます。離すと、その中の点を一度に留める（**Ctrl+Shift** なら外す）ことができます。
- 既定では、**カメラ側を向いた点（表側）だけ**が対象です。裏側も入れたいときは、「道具」の区切りの「四角は表側だけ」をオフにします
- 他の物に隠れているかどうかは見ません（重なった布も、画面に入れば対象になります）
- 対称がオンなら、反対側も同じようになります
- 四角が小さすぎる（4 ピクセル未満）ときは何もしません。Esc で取り消せます

### 部品ごと（ダブルクリック）
ピン留めの道具で**ダブルクリック**すると、クリックした**部品（つながった 1 枚の布＝島）全体**を留めます（**Ctrl** を押していれば外します）。
スカートの内側のペチコート全体を固定したいときなどに便利です。

### すべて外す・反転
「道具」の区切り（編集中。くわしく）のボタンです。
- **ピンをすべて外す**: ピン留めをすべて外す
- **ピンを反転**: 留めた所を外し、留めていなかった所を留める（「この辺りだけ動かす」ときに、動かす所以外を留めるのに便利）

どれも **Ctrl+Z** で 1 回で戻せます。

## 7. 選んで動かす（点を選んで、ハンドルで動かす）

布を「つまむ」代わりに、**点を選んで、ハンドルで動かす・回す・拡大縮小する**道具です。EreMorph の「頂点を選んで、ハンドルで動かす」に当たります。
「ここから、ここまでを、ぴったり 3cm 下げる」「決まった範囲を決まった角度だけ回す」「裾を長くする」のように、**動かす量を自分で決めたいとき**に使います。

点の位置を見ながら動かすので、つまむ道具より細かく指定できます。ピン留めも、Ctrl+Z も、シェイプキーへの保存も、ほかの道具と同じように使えます。

かんたん表示では、「選んだ点」の区切りに、ハンドルの種類・動かし方（布として動かす／形だけ動かす）・なめらかさの半径だけが出ます。中心と向き（7-4）・減り方・選択のボタン（7-7）・数値で動かす（7-8）などは「くわしく」で出ます。

### 7-1. 点とは
- 点は、**布の表面に 1cm 間隔で並んでいる粒子**です（メッシュの頂点とは別のものです）
- メッシュの**頂点は、近くの点についていきます**。頂点が粗い衣装でも、1cm の細かさで選べて、動かせます
- 選べる点の数は、ウィンドウの一番下の「点」（くわしく表示では「粒子」）の数に出ます

### 7-2. 選ぶ
**Q** を押すか、道具の「選んで動かす」を選びます（もう一度 **Q** を押すと、直前の道具に戻ります）。

| 操作 | 内容 |
|---|---|
| ドラッグ（クリックも） | ブラシ半径で**塗って選ぶ**（加える）。半径は **Ctrl+ホイール** か `[` `]` |
| **Ctrl**+ドラッグ | 塗って**外す** |
| **Shift**+ドラッグ | **四角く囲んで**選ぶ（加える）。布に当たらない所からも始められる |
| **Ctrl+Shift**+ドラッグ | 四角く囲んで外す |
| **ダブルクリック** | クリックした**部品（つながった 1 枚の布＝島）ごと**選ぶ（**Ctrl** で外す） |
| 何もない所をクリック | 選択を**解除** |
| **Esc** | 操作の途中なら取り消し。何もしていなければ、選択を解除 |

- ダブルクリックは、1 回目のクリックで塗った所を含めて、その部品全体を選びます
- マウスの下では、塗ると選ばれる点（同じ部品の、ブラシ半径の中）が**薄いピンク**で見えます。ブラシの円もピンクです
- 選んだ点は**橙**で出ます。多いときは間引いて表示します（動かす計算は、全部の点で行います）
- 四角く囲むときは、既定では**画面に見えている点だけ**を選びます（他の布に隠れた点や裏側は選びません）。隠れた点も選びたいときは、「選んだ点」の区切りの「隠れた点も選ぶ」をオンにします
- 選択は Ctrl+Z では戻りません（動かした形とピンは戻り、選択は残ります）。選び直したいときは **Esc** か「選択を解除」

### 7-3. ハンドルで動かす
点を選ぶと、**ハンドル**が出ます。ハンドルをドラッグして動かします。

| キー | ハンドル |
|---|---|
| **W** | 移動 |
| **E** | 回転 |
| **R** | 拡大縮小（軸ごとにも変えられます） |

- 「選んで動かす」の間は、W/E/R は**ハンドルの種類**を切り替えます（道具は「選んで動かす」のままです）。**P**・**Shift+P**・**T** は今までどおり道具を切り替えます
- **Shift** を押しながらドラッグすると、動きが 1/5 のゆっくりになります
- **Ctrl** を押しながらドラッグすると、Unity の標準のスナップ（刻み）が効きます
- ドラッグ中に **Esc** で、押す前に戻ります。離すと周りの布が落ち着き（仕上げ）、**Ctrl+Z** で 1 回で戻せます
- ハンドルの上のクリックは、ハンドルが優先です（点を塗って選び始めません）
- **ピン留めした点は、選んでも動きません**。ウィンドウに注意が出ます
- ハンドルの近くに、選んでいる点の数が出ます

### 7-4. 中心と向き
ウィンドウの「選んだ点」の区切りで決めます。

| 設定 | 内容 |
|---|---|
| 中心 | 回転・拡大縮小の中心で、ハンドルが出る位置です。**選んだ点の中心**（今の位置の平均）／**クリックした点**（最後にクリックして選んだ、面の上の点）／**3D カーソル**（**Shift**+右クリックで布の上に置いた点。「カーソルを選んだ点の中心に」でも置ける。シーンビューに赤い十字で出る。置いていなければ選んだ点の中心） |
| 向き | ハンドルの軸の向きです。**グローバル**（ワールドの軸）／**アバター**（アバターの向き）／**面の法線**（選んだ点の面の向きが Z）／**視点**（画面の右・上・奥） |

動かしている間、ハンドルは押した位置・向きのまま動きません。

### 7-5. 動かし方（布として動かす／形だけ動かす）
「選んだ点」の区切りの「動かし方」で切り替えます。

| | 布として動かす（既定） | 形だけ動かす |
|---|---|---|
| 動き | 選んだ点を動かすと、**周りの布が布の計算で付いてくる**。伸びない | 選んだ点と、なめらかに減る範囲を、**指定どおりの位置**へ動かす |
| 布の長さ | 保たれる。**布の長さで届かない所へは、手前で止まる** | 保たれない。**布が伸びることがある** |
| 仕上げ | 離すと周りの布が落ち着くまで計算する | 計算しないので、離すとその場で確定する |
| 向いている編集 | 形を自然に変える。裾を外へ広げる、ひだを寄せる、ずらす | **布の長さが変わる編集**。裾を長くする・短くする、幅や丈を変える |

使い分けの目安:
- まず**布として動かす**で試します。伸びずに自然な形になります
- 動かしたい量が大きく、手前で止まってしまう（布の長さで届かない）ときは、**形だけ動かす**に切り替えます。たとえば**裾を長くする**編集は、布の長さを変えるので「形だけ動かす」で行います
- 「形だけ動かす」で動かしたあと、伸びが気になるときは、「表示」の「伸びのヒートマップ」で確かめます

### 7-6. なめらかさ
「選んだ点」の区切りの「なめらかさの半径（cm）」（0〜30）は、選んだ点の端から、動きが**なめらかに減っていく範囲**です。
- 0 なら、選んだ点だけが動きます（周りの布は、布の計算で付いてきます）
- 大きくすると、選んだ点の周りも一緒に動き、境目が目立ちません
- 「減り方」で、減り方（一定・なめらか・直線・鋭い・球・自由に描く）を選べます。**ブラシの「減衰カーブ」とは別の設定**です（「自由に描く」のときだけ、ブラシで描いたカーブを使います）
- 「範囲の色分け」をオンにすると、なめらかに減る範囲の点が、動きの強さで色分けして出ます（強い所は黄、弱い所は青）。動かしている間は、動かしている範囲が同じ色で出ます

### 7-7. 選択の操作（ボタン）
「選んだ点」の区切りのボタンです。

| ボタン | 内容 |
|---|---|
| すべて選ぶ／選択を解除／反転 | 全部を選ぶ／全部を外す／選んだ点と選んでいない点を入れ替える |
| 広げる／狭める | 選択を 1 周ぶん広げる／縁の 1 周ぶんを外す（同じ部品の中だけ） |
| 左右の反対側も選ぶ | 選んだ点を鏡に映した、反対側の点も選ぶ。左右の中心は「対称」の軸と中心のずれで決まる（対称がオフでも使える） |
| 選んだ点をピン留め | 選んだ点をピン留めする（Ctrl+Z で戻せる） |
| ピン留めした点を選ぶ | ピン留めした点を、選択に足す |

### 7-8. 数値で動かす
「選んだ点」の区切りの「数値で動かす」を開くと、数値で指定して動かせます。
- **移動（cm）**・**回転（°）**・**拡大（%）** を、X/Y/Z の軸ごとに入れて「適用」を押します（100% で変わりません）
- 軸は、**今のハンドルの向き**（グローバル／アバター／面の法線）の軸です。回転と拡大の中心は「中心」の設定です
- ハンドルで同じ値まで動かしたときと同じ結果になり、**1 回の適用が Ctrl+Z の 1 段**です
- 「値をリセット」で、入力欄を移動 0・回転 0・拡大 100% に戻します

### 7-9. 対称
対称編集がオンのときは、**反対側が自動で鏡に映して動く**ので、反対側を選ばなくてかまいません（ウィンドウにも一言出ます）。反対側に動く点は、薄い橙で出ます。
中央線をまたいで選んだ場合は、鏡の面に沿う動きだけになります。

### 7-10. ショートカット（選んで動かす）
| キー・操作 | 内容 |
|---|---|
| **Q** | 「選んで動かす」に切り替え。もう一度押すと直前の道具 |
| **W** / **E** / **R** | ハンドルを 移動／回転／拡大縮小 に切り替え |

| **Shift**+ドラッグ／**Ctrl+Shift**+ドラッグ | 四角く囲んで選ぶ／外す |

## 8. 保存とシェイプキーの一覧

### 8-1. シェイプキーとして保存
ウィンドウの上（「編集を終了」の隣）の「**保存**」を押すと、「保存」の区切りの名前の欄にある名前で保存します（「保存」の区切りで名前を決めて「シェイプキーとして保存」を押しても同じです）。シェイプキーの一覧の「布で再編集」で始めたときは、上の「保存」は、同じ名前で上書き保存します。保存すると、
- 元のメッシュの複製（`Assets/GP02/Meshes/`）に、シェイプキー（BlendShape）として入ります
- 編集の内容は**データ**（`Assets/GP02/Data/`）にも記録されます。ピン留めも一緒に残るので、**あとで再編集**できます
- **Ctrl+Z** で、保存を取り消せます

同じ名前のシェイプキーがメッシュにあるときは保存できません。別の名前にしてください。

保存すると、「保存」の区切りに**保存したシェイプキーの一覧**が出ます（かんたん表示でも出ます。6個まで）。
- 名前の右の表示: そのシェイプキーが、いま衣装に**反映中（100）**か、**反映していない（0）**かが出ます（衣装に入っているシェイプキーの、実際の重みです。重みは Inspector の「Blend Shapes」で 0〜100 に変えられます）。メッシュに書き出していないものは「反映していない（未書き出し）」と出ます
- 「重ねて見る」のスライダー（くわしく表示）: 重みを動かすと、編集中の形に**保存した形が橙の半透明で重なって**見えます。確かめるためだけのもので、データの重みは変わりません
- **［布で再編集］**: 保存した形を読み込んで、続きを編集します（直したら、同じ名前で上書き保存できます）
- **［削除］**: 確認のあと、一覧から消します（自動でバックアップが残ります。メッシュに書き出し済みのシェイプキーは残ります）
- **［詳しい一覧を開く］**: シェイプキーの一覧のウィンドウを開きます

### 8-2. シェイプキーの一覧
メニュー **Tools → GP02 → シェイプキーの一覧**、または衣装の `GP02 Shape Keys` コンポーネントの Inspector で開きます。
保存したシェイプキーを並べて、確かめたり、加工したりします。
一番上の「かんたん／くわしく」（布の編集ウィンドウと共通）で、出す操作の量を切り替えます。かんたん表示では、**有効・名前・重み・複製・削除・左右に分割・左右反転・メッシュへの反映**だけが出ます（複製・削除・左右に分割・左右反転は、一覧でシェイプキーを選ぶと使えます）。次の一覧のうち、検索・並べ替え、コピー・貼り付け、グループ、ソロ、合成、取り込み、バックアップなどは「くわしく」で出ます。

- **重みのスライダー**: 形を確かめるための重み。その場でシーンのメッシュに見せる（プレビュー。ウィンドウを閉じる・別の物を選ぶと元に戻る）。メッシュ（インスペクター）の BlendShape の重みは変わりません
- **布で編集する**（右クリック）: 保存したシェイプキーを、布として続きから編集する。「同じ名前で上書き保存」か「別名で追加」で戻せる
- **複製・コピー・貼り付け・削除**: 頂点数が同じメッシュなら、別のデータにも貼れる
- **グループ・有効／無効・並べ替え**: ドラッグで並べ替え、グループにまとめる。無効にしたものはメッシュに反映されない。選んだものをまとめて有効・無効にするボタン（一覧の上の「有効」「無効」）もある
- **検索・並べ替え**: 一覧の上の検索欄に、名前に含まれる文字を入れると絞り込む（空白で区切ると、すべて含むものだけ）。右の欄で「データの順／名前／作った順」に並べ替える。どちらも**表示だけ**で、データの並びは変わらない（「この並びで確定」でデータの並びにできる）。検索・並べ替え中は、ドラッグと ▲▼ での並べ替えはできない
- **これだけ表示（ソロ）**: 行の「S」ボタン（または右クリック）で、そのシェイプキーだけをシーンに見せる。他のシェイプキーの重みは変えない。スライダーが 0 のときは 100 で見せる。無効にしてあるものも確かめられる。一覧の上の「ソロ解除」で、重みどおりのプレビューに戻る
- **青い背景の行**: 「素体に焼き込む」の印があるもの（8-8）
- **合成**: 選んだものを、重みをかけて足して 1 つにする
- **差し引き（上 − 下）**: 選んだ 2 つのうち、一覧で上にあるものから下にあるものを引いた新しいシェイプキーを作る（重み 100 での形で引く）。「逆」を入れると、下 − 上
- **左右に分割**: `_L` と `_R` の 2 つに分ける（足すと元に戻る）。中央のなめらかさの幅は「操作の設定」で決める。「操作の設定」で軸（X/Y/Z）を選べて、「分割の軸をアバターのローカルで見る」をオンにすると、軸と中心をアバターのルート（Animator のある親）の座標で見る（メッシュが回転・拡大縮小されていても、アバターの左右で分けられる）
- **左右反転・左右対称にする**: 反対側へ写す。軸・中心・鏡像を探す距離は「操作の設定」
- **量を拡大縮小**: 差分を何 % かにする（150% で 1.5 倍）
- **in-between にする（順に並べる）**: 選んだものを順に並べて、途中の段（in-between）つきの 1 つにする。Crossfade／Progressive を選べる
- **法線を計算し直す**: 次の 8-4 を参照
- **選んだ点で分割・範囲だけ取り出す・範囲を消す**: 8-10 を参照
- **別のメッシュへ写す**: 8-11 を参照
- **選んだシェイプキーの詳細**（素体に焼き込む印・in-between のフレーム・前の版）: 8-8、8-9、8-12 を参照

### 8-3. 取り込み
一覧の「取り込み」の区切りから、既存のシェイプキーを一覧に入れます。入れたものは、加工したり、布として再編集したりできます。
- **元メッシュの BlendShape から**: メッシュに入っている BlendShape（まとめて全部、または 1 つ）
- **別のメッシュから**: そのメッシュとの差を取り込む（頂点数が同じこと）
- **AnimationClip から**: 時刻を決めて、その時刻の BlendShape の値を取り込む。「**すべてのキーフレームを in-between として取り込む**」を押すと、クリップの BlendShape のキーフレームの時刻ごとの形を、1 つのシェイプキーの in-between のフレームにする（フレームは時刻の順に等間隔の重み。BlendShape の値がすべて 0 の時刻は元の形なので入れない。キーフレームの時刻が 32 を超えるときは、減らしてから取り込む）
- **同じ名前は上書きする**: オンにすると、取り込むシェイプキーと同じ名前のものがあれば、新しく作らずそれを上書きする。上書き前の形は「前の版」に残る（8-12）

### 8-4. 法線を計算し直す
シェイプキーは、位置の差分に加えて**法線の差分**も持ちます。法線が合っていないと、動かしたときに陰影がおかしく見えます
（UV の継ぎ目だけ色が違う、取り込んだシェイプキーの陰影が変、など）。そのようなときは、選んだシェイプキーを選び、
「選んだシェイプキーへの操作」の「**法線を計算し直す**」を押します（右クリックメニューにもあります）。
既存の BlendShape から取り込んだものにも使えます。Ctrl+Z で戻せます。

「操作の設定」に、次の 2 つがあります。
- **法線のスムーズ角度（°）**: 同じ位置にある頂点の面を、この角度以内ならなめらかにつなぎます。**180（既定）で全部つなぎます**。固いエッジ（角）を残したいときは小さくします（例: 60）。角度は元の形で判定します
- **法線: 同じ位置の頂点を結合**: UV の継ぎ目などで分かれた頂点の法線をそろえます。オフなら、頂点ごとに、それぞれの面だけで計算します（このときスムーズ角度は効きません）

### 8-5. メッシュへの反映
一覧の「メッシュへの反映」の区切りです。シェイプキーのデータ（一覧）を、衣装のメッシュ（元のメッシュの複製）に BlendShape として入れます。
布の編集の「シェイプキーとして保存」（8-1）は、データとメッシュの**両方に入れる**ので、保存した直後はもう反映済みです。押し直す必要はありません。

- **かんたん表示**: データと、レンダラーに今付いているメッシュの BlendShape を比べて、
  - 同じなら「**✓ メッシュに反映済み**」の 1 行だけが出ます
  - 違うときだけ「**メッシュに反映（変更 N 件）**」のボタンが目立つ色で出ます。上に「メッシュと違う所: 加わる: GP02_2 ／ 置き換わる: GP02_1」のように、何が変わるかが 1 行で出ます（データで形を変えた・無効にした・消した・名前の前置きを変えた、元のメッシュに戻した、など）
  - 比べるのは、名前と、各フレームの重み・頂点ごとの差分です（ごくわずかな違いは同じとみなします）。元のメッシュにもとからある BlendShape は、名前だけを見ます。「素体に焼き込む」の印の分（素体の形）と、ウェイトの変更（13-5）が入っていないことも数えます
  - 「適用のしかた」が「ビルド時に適用（NDMF）」（8-7）のときは、シーンのメッシュは変えない設定なので、ボタンは出さず、その旨を 1 行で出します
- **反映の内容（実行前の確認）**（くわしく表示）: 「メッシュに反映」を押す前に、何が起きるかが一覧で見える。**追加**（新しい BlendShape）・**上書き**（同じ名前の BlendShape を置き換える）・**別名**（同じ名前があるので「名前 (1)」で加える）・**焼き込み**（素体に焼き込む）・**飛ばす**（差分が無い、頂点数が違う）・**エラー**（名前が空など。反映できない）。行にマウスを乗せると理由が出る。実際の反映は、この一覧のとおりに行われる（この一覧は、元のメッシュから作り直すときの内容です。今のメッシュとの違いは、その下の 1 行に出ます）
- **名前の前置き・後置き**: メッシュに入れる BlendShape の名前の前と後ろに付ける文字（例 `GP02_`）。データのシェイプキーの名前は変わらない。コンポーネントに保存されるので、アップロード時の自動適用（8-7）でも同じ名前になる。前置きを付ければ、元のメッシュの BlendShape と名前がぶつからない
- **頂点数が違うものは飛ばして反映する**: オフ（既定）だと、頂点数がメッシュと合わないシェイプキーがあるとき、反映（とアップロード）が失敗する。オンなら、そのシェイプキーだけ飛ばす（アップロード時は警告が出る）
- **メッシュに反映（変更 N 件）**: 有効なシェイプキーを、元のメッシュの複製に BlendShape として入れ、保存してレンダラーに割り当てる。データは残る。くわしく表示では、反映済みでも押せる（作り直したいとき）。「同じ名前を上書きする」がオフなら、同じ名前は「名前 (1)」のように別の名前で入る
- **選んだものを素体に焼き込む**: 選んだシェイプキーを、スライダーの重みで素体の形に焼き込んだメッシュを作る。「大きく動いた頂点のウェイトを付け替える」をオンにすると、大きく動いた頂点のボーンウェイトを付け替える（裾を短くしたら手のウェイトが残っていた、などを防ぐ）。付け替えかたは 2 つ
  - **近くの頂点からもらう**: 動いた先に一番近い頂点のウェイトをもらう
  - **左右を反転したウェイトをもらう**: 左右の境（「操作の設定」の軸と中心）を越えて反対側へ動いた頂点だけ、自分のウェイトのボーンを左右反対のボーンに付け替える（左の頂点が右側へ動いたら、右のボーンのウェイトにする）。ボーンの左右の対応は名前で決める（`Left`/`Right`、`.L`/`.R`、`_L`/`_R`、`L_`/`R_`、`左`/`右` など。背骨のように相手がいない骨はそのまま）
  - **なめらかにする回数**: 付け替えた頂点のウェイトを、隣の頂点となじませる回数（0 でなじませない）
- **元のメッシュに戻す**: レンダラーのメッシュを元に戻す

データ（アセット）を削除しても、反映したメッシュはアセットとして残ります。このツールを消しても、メッシュは消えません。

### 8-6. 重ね着をまとめて編集する
スカートの内側にペチコートがある、などの重ね着は、まとめて1つの布として編集できます。外の布を内へ押すと内の布も一緒に押され、外の布が内の布を突き抜けません。
1. ウィンドウの「対象」で、外の布を設定する
2. 「同じアバターの重ね着をまとめて追加」を押す（対象と面が近い同じアバターのメッシュが追加される）。手で選ぶときは、ヒエラルキーで選んで「選択中のオブジェクトを追加」
3. 「編集を開始」。つまむ・ピン留め・保存は全部の層にまとめて効く
4. 保存すると、それぞれのメッシュに同じ名前のシェイプキーが入る。Ctrl+Z で全部まとめて戻る

- 1つのメッシュの中に層がある場合（裏地が同じメッシュに入っているなど）は、まとめて追加しなくても層どうしが押し分けられます
- 層が増えると計算が重くなります。Burst を入れておくのがおすすめです
- 押し分けを止めたいときは、詳細設定の「重ね着の層を押し分ける」をオフにします

### 8-7. アップロード時に自動で入れる（NDMF）
NDMF（Modular Avatar などが使う仕組み）が入っているプロジェクトでは、シーンのメッシュを変えずに、アバターをアップロード（ビルド）するときだけシェイプキーを入れられます。
1. 衣装の「GP02 Shape Keys」コンポーネント（または、シェイプキーの一覧）で、「適用のしかた」を **ビルド時に適用（NDMF）** にする
2. 「ビルド時の最初の重み」で、入れたシェイプキーの最初の重み（0、または一覧のスライダーの値）を選ぶ
3. そのままアップロードする。Modular Avatar より前に処理されるので、Modular Avatar の設定からもシェイプキーを使える

- 元のメッシュはそのまま残るので、他のメッシュ編集ツールと競合しにくくなります
- NDMF が入っていないときは、この設定を選んでも自動では入りません（画面に案内が出ます）。「メッシュに反映」を使ってください
- 「メッシュに反映」で作ったメッシュを割り当てたままにしている場合は、「適用のしかた」を **メッシュに反映する** にしておきます

### 8-8. 素体への焼き込みの印（Prebake）
シェイプキーに「**素体に焼き込む**」の印を付けると、そのシェイプキーは BlendShape にならず、**メッシュへの反映（とアップロード時の自動適用）のときに、先に素体の形に焼き込まれ**ます。常に着せたままにする形の補正（腰を少し細くする、など）に使います。
1. 一覧でシェイプキーを選び、「選んだシェイプキーの詳細」の「素体に焼き込む」をオンにする（右クリックの「素体に焼き込む印を付ける」でも可。複数まとめて付けられる）
2. 「焼き込む重み」（0〜100、既定 100）で、どれだけ焼き込むかを決める
3. メッシュに反映する。印のあるものは「反映の内容」に**焼き込み**と出る。印のある行は一覧で**青い背景**になる

- 印はデータに残ります。**印を外して反映し直せば、素体は元に戻ります**（反映は、毎回、元のメッシュから作り直すため）
- 「選んだものを素体に焼き込む」ボタンは、その場で 1 回だけ焼き込んだメッシュを作る別の機能です。印は、反映するたびに焼き込む方式です
- 印のあるシェイプキーのプレビューは、ふつうのシェイプキーと同じようにスライダーで確かめられます

### 8-9. in-between のフレームを確かめる・直す
in-between のあるシェイプキーを 1 つ選ぶと、「選んだシェイプキーの詳細」に**フレームの一覧**が出ます。
- **重み**: フレームごとの重み（0.01〜100）。変えると、重みの順に並び直される。他のフレームと同じ重みにはできない
- **この重みで見る**: そのフレームの重みでシーンに見せる
- **削除**: フレームを消す（最後の 1 つは消せない）。消す前の形は「前の版」とバックアップに残る
- **補間のプレビュー**: スライダーを 0〜100 で動かして、フレームの間の補間をシーンで確かめる（そのシェイプキーだけを見せる。「ソロ解除」で戻る）

### 8-10. 選んだ点の範囲で分ける・取り出す・消す
布の編集で選んだ点（「7. 選んで動かす」）を、シェイプキーを分ける範囲として使えます。一覧の「選んだシェイプキーへの操作」の「選んだ点の範囲で分ける・取り出す・消す」です。
1. 一覧でシェイプキーを選び、「布で編集する」でそのメッシュの編集を始める（または、ウィンドウでそのメッシュの編集を始める）
2. 布の編集の「選ぶ」道具で、範囲にしたい点を選ぶ
3. 一覧で次のどれかを押す
   - **選んだ点で分割**: 範囲の中（`_Sel`）と残り（`_Rest`）の 2 つに分ける。足すと元に戻る
   - **範囲だけ取り出す**: 範囲の中だけを残した新しいシェイプキー（`_Sel`）を作る
   - **範囲を消す**: 範囲の中を消した新しいシェイプキー（`_Rest`）を作る
- **境目のなめらかさ（回数）**: 範囲の境目の頂点を、隣の頂点となじませる回数。大きいほど境目がなだらかになる（0 だと、選んだ点のそのままの境目）
- 「取り出す・消すは別のシェイプキーにする」をオフにすると、選んだシェイプキーを書き換える（前の形は履歴とバックアップに残る）
- 頂点は近くの点（粒子）についていくので、範囲の頂点の重みは「結びついた点のうち、選ばれている点の割合」になり、境目は自然に途中の値になる

### 8-11. 別のメッシュへ写す（頂点数が違ってもよい）
選んだシェイプキーを、頂点数の違う別のメッシュ用のデータへ写せます（例: 別の素体用に作り直した服、細かくした・粗くしたメッシュ）。一覧の「別のメッシュへ写す」です。
1. 「写し先」に、写し先の Mesh、`GP02 Shape Keys` のあるオブジェクト、またはシェイプキーのデータを指定する（Mesh を指定すると、そのメッシュのデータを探し、無ければ作る）
2. 「距離の上限（cm）」を決める。既定は 2cm
3. 「選んだシェイプキーを写す」を押す

- 写し先のメッシュの頂点ごとに、元のメッシュの**元の形の表面で一番近い点**（三角形の上の点）を探し、その三角形の 3 頂点の差分を重心座標で混ぜて写します。位置・法線・接線のすべてのフレーム（in-between も）を写します
- **距離の上限を超える頂点**は、差分が 0 になります（写した数と、0 になった頂点の数が画面に出ます）
- 「法線が逆向きの面を避ける」がオンなら、薄い服の裏側のように、向きが逆の面からは写しません
- 2 つのメッシュは、**同じ座標系**（同じ向き・大きさ・位置）にしてください
- 写し先のデータに新しいシェイプキーとして加わります（名前が重なるときは番号が付く）。元のデータは変わりません。ピン留めは頂点の番号が変わるので引き継ぎません
- EreMorph は頂点数が違うと使えませんが、GP02 は使えます

### 8-12. 前の版に戻す（履歴）と、自動バックアップ
**前の版**: シェイプキーを**上書き**するたび（布で編集して上書き保存、取り込みで上書き、量の拡大縮小・左右反転を元に書き換える・法線の計算し直し・フレームの削除など）に、上書きする前の形をシェイプキーの中に残します。**最大 10 個**で、日時と、何をしたときのものかが付きます。同じ形で上書きしたときは増えません。
- シェイプキーを選ぶと、「選んだシェイプキーの詳細」に版の一覧が出ます。**戻す**を押すとその版に戻ります（右クリックの「以前の版に戻す」からも選べます）
- 戻す前の形も新しい版として残るので、戻したあとでも戻れます。**Ctrl+Z** でも戻せます

**自動バックアップ**: データを変える操作（削除・合成・分割・上書き・履歴から戻す・フレームの削除など）の前に、データのアセットの写しを `Assets/GP02/Backups/`（データごとのフォルダ）に残します。**データごとに最新 5 個**だけ残り、古いものは消えます。
- 一覧の「バックアップ（自動）」と、データのアセット（`Assets/GP02/Data/` の中のもの）の Inspector に、一覧と「**バックアップから戻す**」があります。データ全体がそのときの状態に戻ります（戻す前の状態もバックアップに残り、Ctrl+Z でも戻せます）
- Unity を閉じたあとや、Ctrl+Z の履歴が消えたあとでも戻せます
- アセットとして保存されていないデータは、バックアップを取れません

### 8-13. トグル用の AnimationClip と、重ね着のまとめて反映
**トグル用の AnimationClip**: メッシュへの反映の「トグル用の AnimationClip も作る」をオンにして反映する（または「AnimationClip だけ作る」を押す）と、BlendShape になるシェイプキーごとに、**重み 0 のクリップ**と**重み 100 のクリップ**を `Assets/GP02/Animations/` に作ります（`衣装の名前_BlendShape名_Off.anim` と `_On.anim`）。
- クリップのパスは、**アバターのルート**（Animator のある一番上の親）からのレンダラーのパスです。VRChat の FX レイヤーなどのステートに、そのまま使えます
- もう一度作ると、同じクリップの中身だけが置き換わるので、アニメーターからの参照は保たれます
- 焼き込みの印のあるもの、無効なものは作りません。SkinnedMeshRenderer が必要です

**重ね着のまとめて反映**: 同じアバターの下に `GP02 Shape Keys` が 2 つ以上あると、メッシュへの反映の区切りに「**このアバターの GP02 をまとめてメッシュに反映**」が出ます。押すと、実行の前に、衣装ごとの内容（追加・上書き…の数）が出るので、確かめて「反映する」を押します。1 つが反映できなくても、残りは続けて反映し、できなかったものは理由が出ます。名前の前置き・後置きは、衣装ごとの設定が使われます。

## 9. 詳細設定の調整のしかた

ウィンドウの上の「くわしく」に切り替えて「詳細設定」を開くと、計算の値を変えられます。値は自動で保存され、「既定に戻す」（道具・ブラシ・対称・表示を含むすべて）で元に戻せます。
**こう感じたら、この値**、の目安です。

| 感じたこと | 変える値 | 向き |
|---|---|---|
| 手を離したあと、形が落ち着くまでが長い | 1回の更新の計算時間（既定 12ms） | 大きく（操作は重くなる） |
| 仕上げが途中で打ち切られて、伸びが残る | 仕上げの時間切れ（既定 2秒） | 長く |
| 仕上げが終わるのが待ちきれない | 仕上げの許容する伸び（既定 1%） | 大きく（少し雑になる） |
| 布がペラペラに折れすぎる／硬すぎる | 曲がりやすさ（既定 0.1） | 硬く＝小さく、柔らかく＝大きく |
| 引っ張った所が手からずれる（遅れる） | つまむ柔らかさ（既定 0.02） | 小さく |
| 大きく引いたときに伸びが残る | つまむ柔らかさ | 大きく（届かない所では早く手前で止まる） |
| 布が体や内側の布に食い込む | 元の形より内側に入らない（既定オン） | オンになっているか確認 |
| わざと内側へ押し込みたい（タックを寄せる等） | 元の形より内側に入らない | オフ |
| ふんわりした服なのに、内側へ動けずに伸びる | 体や内側の布までの隙間を使う（既定オン） | オンになっているか確認 |
| 遠くの布まで動きが伝わりにくい | 粗い段の反復回数（既定 10） | 大きく（重くなる） |
| 引っ張りたい範囲が狭い／広い | ブラシ半径（既定 3cm）、影響範囲（既定 30cm） | ウィンドウの上の方のスライダー |

そのほか:
- **伸びやすさ**（既定 0）: 0 で布は伸びません。強く引くと、布が浮き上がって手前で止まります
- **高速版を使う**: オフにすると Burst を使わず C# で計算します（速さの比較用）

## 10. 困ったとき（よくある質問）

**Q. 「編集を開始」を押しても始まらない／黄色や青い枠が出る**
A. 「診断」の区切りの文章が理由と直し方です（「直す」ボタンで直せるものもあります）。よくあるのは次のとおりです。
- 対象にメッシュが無い、または三角形（面）が無い → メッシュのある SkinnedMeshRenderer（または MeshFilter 付きの MeshRenderer）を指定する
- **Read/Write が無効** → 枠の「Read/Write を有効にする」ボタンで直ります（モデルの Import Settings の Read/Write と同じです）
- 頂点が非常に多い → 準備に数秒〜10 秒かかります。Burst を入れると編集が速くなります

**Q. アバター全体を選んだら、ダイアログが出ずに、「対象」に衣装の一覧が出た**
A. 仕様です。アバター全体のように、衣装そのものではないものを選ぶと、「対象」の区切りに「この中の衣装」の一覧が出ます。編集する衣装のボタンを押してください（体のようなメッシュは、一覧の最後に「体のようです」と出ます）。右クリックの「GP02 で布を編集」や「選択中のオブジェクトから設定」でも同じです。

**Q. 「体のメッシュのようです」と出た**
A. 対象にしたメッシュが、体（素体・顔）に見えます（名前に Body・体・Face・顔 などが付く、または表情のシェイプキーが多い）。服を編集するときは、診断の下の「衣装の候補」や「この中の衣装」の一覧から、服のオブジェクトを選び直してください。体のメッシュそのものを編集したいときは、そのまま「編集を開始」できます（編集は止めません）。

**Q. 編集中、Unity の移動・回転・拡大縮小のハンドルが消えた**
A. 仕様です。GP02 の点やハンドルと重なって紛らわしいので、編集中は Unity 標準のハンドルを隠します。「編集を終了」で（ウィンドウを閉じたとき・プレイモードに入るとき・コンパイルのときも）元に戻ります。

**Q. W / E / R を押すと、Unity 標準の移動・回転・拡大縮小に切り替わってしまう**
A. シーンビューを一度クリックして（シーンビューが選ばれた状態にして）から押してください。GP02 のキーは編集中のシーンビューだけで有効です。編集中でないとき、右クリックを押しながらのとき、Alt や Command を押しているときは、Unity 標準のままです。
**Edit → Shortcuts** の「GP02」で、キーが変えられていないかも確かめてください。

**Q. 「選んで動かす」で選んだ点が動かない／途中で止まる**
A. 次を確かめてください。
- 選んだ点が**ピン留め**されていないか（ピン留めした点は動きません。ウィンドウに注意が出ます）
- 布の長さで届かない所まで動かしていないか → 「動かし方」を**形だけ動かす**にすると、指定どおりに動きます（布が伸びることがあります）
- 数値で動かすときは、「適用」を押したか、動きが 0 でないか

**Q. 「選んで動かす」のハンドルが出ない／Q を押しても切り替わらない**
A. 点を選ぶとハンドルが出ます。シーンビューにマウスを乗せて、Q を押してください（右クリックを押しながら、Alt や Command を押しているときは、Unity 標準のままです）。

**Q. ブラシの円が出ない**
A. マウスを布の上に乗せてください（布に当たったときだけ出ます）。Alt を押している間は視点操作です。

**Q. 引っ張ったのに、布が手に付いてこない／途中で止まる**
A. 布の長さで届かない所まで引くと、布は伸びずに手前で止まります（伸びない仕組みです）。そのとき、シーンビューに橙の線（引いている先と止まった点を結ぶ）と「布の長さが足りず、ここで止まりました。選んで動かす（Q）の『形だけ動かす』なら届きます」の一言が出ます。引きたい量が大きいときは、「選んで動かす」の**形だけ動かす**を使ってください（くわしく表示なら、「伸びやすさ」を上げても届きます）。それ以外は、「詳細設定」の「つまむ柔らかさ」を小さくするか、ピン留めの位置を見直してください。

**Q. コンパイルやプレイモードのあとで、編集が消えた**
A. 保存していない編集は、コンパイル・プレイモード・ウィンドウを閉じるときに自動で取っておきます。同じ衣装を対象にすると、ウィンドウの上に「前回の編集が残っています」の帯が出るので、**［戻す］**を押してください（2-6）。衣装を動かした・別のメッシュに替えたなどで戻せないときは、帯に理由が出ます。元に戻してからもう一度試してください。

**Q. 回す・拡大縮小のボタンが無い／ピン解除の道具が無い**
A. 回す・拡大縮小のボタンは、「くわしく」に切り替えると出ます（キーの **E**・**R** は、かんたん表示でも使えます）。ピン解除は、ピン留めの道具に統合しました。**Ctrl+ドラッグ**で外すか、「塗ると外す」をオンにしてください（6）。

**Q. 大きく引いたあと、伸びが残る**
A. 体にぴったりの服や、重ね着の外側の布を、届かない方向へ大きく引くと、伸びが残ることがあります。「伸びのヒートマップ」で確かめ、引く量を減らすか、「つまむ柔らかさ」を大きくしてください。

**Q. 布が体や内側の布にめり込む**
A. 「詳細設定」の「元の形より内側に入らない」がオンか確認してください。裏面用に面が重なっている部分や、平らな部品には効きません。

**Q. 体のシェイプキーを変えたら（別のアバターに着せたら）、体が服を突き抜けて肌が見える**
A. 「12. 貫通を直す」の手順で、布の長さを保ったまま体の外へ押し出せます。編集中は、操作のたびに自動で調べ直しますが、体のシェイプキーやポーズを変えただけでは調べ直さないので、そのときは「調べ直す」を押してから直してください。

**Q. 対称編集で、反対側が動かない**
A. 反対側の相手が見つからない点（赤紫の点）をつまんでいる可能性があります。衣装がアバターの中心からずれているなら「左右の中心を自動で合わせる」、左右で形が少し違うなら「鏡像を探す許容距離」を広げてください。軸が合っているかも確かめてください。

**Q. 細いリボンやひもがうまく曲がらない**
A. 1cm より細いパーツは、粒子が 1〜2 個しか乗らないので、うまく曲がらないことがあります（既知の制限です）。

**Q. 保存で「同じ名前のシェイプキーが既にあります」と出る**
A. 別の名前にしてください（名前は「保存」の区切りで変えられます）。シェイプキーの一覧の「布で再編集」から始めたときは、上の「保存」で同じ名前に上書きできます。

**Q. 保存したのに、Inspector でシェイプキーが見えない**
A. 保存すると、SkinnedMeshRenderer のメッシュが複製（`_GP02` が付いた名前）に差し替わります。そのメッシュを選んで確かめてください。元のメッシュは変わりません。

**Q. シェイプキーを動かしたら、陰影（色）が変**
A. 「8-4 法線を計算し直す」を試してください。

**Q. エラーが出る／おかしいときに知らせたい**
A. コンソールの赤・黄色のログ（`[GP02]` で始まるもの）、ウィンドウの一番下の状態の1行（点の数・ピン・伸び・高速化・状態。数値は、行にマウスを乗せるか、くわしく表示で見られます）、どんな操作をしたかを添えて知らせてください。購入した衣装そのもののデータは送らないでください。
操作ごとの記録（白いログ）は、ふだんはコンソールに出しません。くわしく表示の「詳細設定」で「**記録をコンソールに出す**」をオンにしてから、同じ操作をもう一度すると出ます。

## 11. EreMorph などの他のツールとの違い

頂点を 1 つずつ選んで動かすタイプのメッシュ編集ツール（EreMorph など）とは、考え方が違います。

| | GP02 | 頂点を選んで動かすツール |
|---|---|---|
| 動かし方 | 布を**つまんで引く**。周りの布が自然に付いてくる。点を選んで、ハンドルで動かす「**選んで動かす**」もある | 頂点を選んで、ハンドルで動かす |
| 布の長さ | **伸びない**（布の長さを保つ計算）。「選んで動かす」の「形だけ動かす」は、布の長さを変える編集向きで、伸びることがある | 頂点の移動なので、伸びても気づきにくい |
| すり抜け | **体・内側の布に入り込まない**（元の形より内側へ入らない、隙間も自動で測る） | 人が見て直す |
| メッシュの細かさ | 1cm の粒子で計算するので、**頂点の密度に左右されない** | 頂点の密度に依存する |
| シーンのメッシュ | **シーンのメッシュを差し替えない**。編集中は表示を重ねて見せ、保存したときだけ、メッシュの複製にシェイプキーを入れる | レンダラーのメッシュを差し替える方式のものがあり、同じ種類のツールと競合しやすい |
| 品質の確認 | 伸びのヒートマップと最大の伸びの数値で見える | 目で見て確かめる |
| 動かさない所 | ピン留め（矩形・部品ごとも） | 選択していない所は動かない |
| 他ツールと併用 | 素の Unity で全機能が動く。VRChat SDK も NDMF も不要 | ツールによる |

布のシワを細かく再現することは重視していません（目的は、衣装の形を自然に変えることです）。

NDMF などの VRChat 向けの機能は、ツール本体とは別の部品として用意します。対象のパッケージが入っているときだけ有効になり、入っていなくてもツール本体には影響しません。

## 12. 貫通を直す（体が布を突き抜けている所）

体のシェイプキー（お尻や胸を大きくする、など）を変えたり、別のアバターに着せたりすると、体が布を突き抜けて肌が見えることがあります。
GP02 は編集を始めたときにこれを調べ、**布の長さを保ったまま、体の外へ押し出して**直せます。周りの布も布として付いてくるので、押し出した所だけが盛り上がることはありません。

### 12-1. 「体」として調べるもの
- 同じアバター（Animator の付いた親）の、**まとめて編集している布以外のオブジェクト**の、今の形（シェイプキーの重みとポーズを含む）です
- そのうち、**布の内側にある部品だけ**を使います。外に重ねた上着や髪、平らな部品（板状の飾りなど）は体として扱いません
- 体が見つからないとき（衣装だけのシーンなど）は調べません。「診断」にそう出ます

### 12-2. 調べる
- 「編集を開始」したとき、保存して編集が作り直されたとき、直したあとに、自動で調べます。さらに、**操作を確定するたびに自動で調べ直します**（つまむ・回す・拡大縮小・選んで動かす・元に戻すブラシを離したとき、Ctrl+Z / Ctrl+Y、外へ逃がす、貫通を直す、など）。そのため、「結果が古いかもしれません」という表示は、ふだんは出ません
- 調べるのに 0.3 秒以上かかる衣装では、操作が重くならないよう、自動の調べ直しをやめます。そのときは、古くなったことが表示されるので、「調べ直す」を押してください。体が見つからないときは調べません
- 結果は「診断」の区切りに出ます。かんたん表示では、突き抜けている所が無いとき、目立たない 1 行「✓ 体との貫通なし」だけが出ます（右の小さな「調べ直す」で、体を集め直して調べられます）。突き抜けている所があるときは、診断の注意に、か所と深さが出ます。くわしく表示では、「体との貫通」の見出しの下に出ます。例: 「体が布を突き抜けている所: 2 か所（最大 13.1 mm、211 点）」（テスト用の衣装では、スカートと、同じメッシュのペチコートで 2 か所）
- シーンビューには、突き抜けている所が**白い縁の赤い点**で出ます（ピン留めの点は青い点です）。直すと消えます
- 数えるのは次の 2 つです
  - 布（の粒子）が体の中に入っている所
  - 体の尖った所が、布の粒子の間から布の外へ出ている所
- 体に近すぎる所（すき間より近い所）は「すき間 2.0 mm より体に近い所: N 点」として別に数え、直すときに一緒に押し出します
- 編集中に体のシェイプキーやポーズを変えたときは、「**調べ直す**」を押してください。体を今の形で集め直してから調べます（操作のたびの自動の調べ直しは、体を集め直しません）

### 12-3. 直す
1. 「体との貫通」の「**貫通を直す**」を押す
2. 突き抜けている所が、体の外（余白の分だけ離れた所）へ押し出されます。数秒かかることがあります（進み具合の表示の「キャンセル」で止められ、そこまでの形が残ります）
3. 「貫通を直しました」と短い通知が出て、詳しい結果（「貫通を直しました: 2 か所 → 0 か所（最大の伸び 2.4%）」）が、編集中の見出しの下の「結果の欄」に残ります。伸びは「伸びのヒートマップ」でも確かめられます
4. 気に入らなければ、**Ctrl+Z の 1 回**で直す前に戻ります（調べた結果と赤い点も、戻した形で出し直します）
5. 形が良ければ、シェイプキーとして保存します

- **ピン留めした点は動きません**。ピン留めした所が体に入っているときは残り、「うち N 点はピン留めなので押し出せません」と出ます。その所のピンを外してから直してください
- 直したあとは、つまんで押し込んでも、**布は体の中へ入りません**（すき間で止まります）。直す前から入っていた所は、直すまでそのままです（勝手には押し出しません）
- ただし、体の鋭い角（粒子の間隔 1cm より細い尖り）に布を強く押し付けると、角が粒子の間から布の外へ出ることがあります（赤い点が出ます）。そのときは、もう一度「貫通を直す」を押してください
- 重ね着をまとめて編集しているとき（8-6）は、外の布に押されて、内の布も一緒に押し出されます
- 1 つのメッシュの中で別の部品が体に入っているとき（ペチコートなど）も、まとめて押し出します
- 布の長さで届かないほど大きく突き抜けているとき（体にぴったりの服で、体が大きく膨らんだ、など）は、押し出しきれずに残ったり、伸びが残ったりします。体のシェイプキーを少し弱めるか、ピンの位置を見直してください
- ウエストのすぐ下が膨らんだときは、ウエストをピン留めしたままだと、布が膨らみを回り込めずに伸びます。ピンを外すか、膨らみから離れた所だけに留めてください

### 12-4. 余白（すき間）
- 「**余白（mm）**」（かんたん表示の文では「すき間」）は、体と布の間に保つ距離です（既定 2mm、0〜10mm）。値は自動で保存され、「詳細設定」の「既定に戻す」で戻ります
- 余白より体に近い所も「貫通を直す」で押し出します。編集中も、布は余白より体に近づきません
- 余白を変えたら、少し待つと自動で数え直します（自動をやめた衣装では「調べ直す」を押します）

### 12-5. 体のシェイプキーを変えたあとに、服を合わせる（例: お尻を大きくした）
1. 体の SkinnedMeshRenderer で、シェイプキー（例: `Hip_Big`）の重みを 100 にする
2. GP02 のウィンドウで服を対象にし、「編集を開始」（すでに編集中なら「調べ直す」）
3. 「体との貫通」と赤い点で、突き抜けている所を確かめる
4. 「貫通を直す」を押す
5. 形を確かめ、必要ならつまんで整えてから、シェイプキーとして保存する（名前の例: `Fit_HipBig`）
6. 体のシェイプキーと服のシェイプキーを同じ重みで動かすと、合った形になります（Modular Avatar などで一緒に動かす）

- 服のシェイプキーの重みは 0 にしてから始めてください（今の重みの形が差分の基準になるため）。体のシェイプキーは変えたままで構いません
- 途中の重み（50 など）でもおおむね合いますが、ぴったりではありません。気になるときは、体を 50 にして同じ手順でもう 1 つ作り、in-between のフレーム（8-9）にします
- テスト用の衣装（2-1）の体には、試すための `Hip_Big` が入っています。100 にすると、後ろの腰で体がスカートを突き抜けます

## 13. 動作チェック（ポーズを変えたときの貫通）

編集の姿勢では大丈夫でも、座る・足を上げる・お辞儀などで、体が服を突き抜けることがあります。
「動作チェック」は、いろいろなポーズを自動で試して、突き抜ける所を探します。**シーンのアバターは動かしません**（見えない複製にポーズを付けて試し、終わったら消します）。

### 13-1. 使えるとき
- 服が、**Animator の付いた Humanoid のアバターの中**にあること（Avatar の Animation Type が Humanoid）。Animator が無い・Generic のときは、「動作チェック」の区切りに理由が出て、使えません
- VRChat SDK も NDMF も要りません
- 服が自分のアーマチュアを持っているとき（Modular Avatar の Merge Armature で着せる服など）も使えます。服のボーンを、名前（`_Outfit` のような前置き・後置きを除く）と位置で体のボーンに対応付け、体と一緒に動かします。対応しないボーンは親に付いていきます
- 「体」は、同じアバターの中で Humanoid のボーンに広くウェイトがあるレンダラーです（無ければ、布の内側にあるほかのレンダラー）。重ね着の内側の布は数えません
- 試すには、「**Tools/GP02/テスト用のアバター（Humanoid）を作る**」で、体・スカート・タイツ・袖の入った Humanoid のアバターが作れます（「服を別のアーマチュアに」の版もあります）

### 13-2. 調べる
1. 服を対象にして「編集を開始」する
2. 「動作チェック」の「**動作チェックを始める**」を押す。数秒かかります（進み具合が出ます。「やめる」で止められ、前の結果は残ります）
3. 結果が出ます。「**よく使うポーズ**」と「**大きく動くポーズ**」に分けて、2 行で出します。例（テスト用のアバターのスカート）:
   - 「よく使うポーズ: 3 / 10 ポーズで 9 か所（最大 10.2 mm）」
   - 「大きく動くポーズ（座る・しゃがむ・足を上げる・開く）: 5 / 5 ポーズで 20 か所。スカートなどでは普通に起きます（VRChat では揺れもの（PhysBone）で動かすことが多いです）」

   よく使うポーズで突き抜けが無いときは「**よく使うポーズでは問題ありません ✓**」を、いちばん目立つ緑の文字で出します。その下に、悪い順の上位と「おすすめの直し方」（13-3）が出ます

- 試すポーズ（15 種類）
  - **大きく動くポーズ**（5）: 座る、しゃがむ、左足を前に上げる、右足を前に上げる、足を横に開く
  - **よく使うポーズ**（10）: 歩く（前後）、腕を下ろす、腕を上げる（バンザイ）、腕を前に、腕を体の前で曲げる、お辞儀、反る、体をひねる、首を回す、体を横に倒す。手持ちの AnimationClip のコマ（13-7）も、よく使うポーズに入れます
- それぞれ「**途中まで**」（ポーズの半分まで動かしたところ）と「**最後まで**」の 2 段階で試します（途中の姿勢でだけ突き抜ける所も見つかります）
- **か所の数え方**: 同じ所でも、ポーズ・段階ごとに 1 か所と数えます（「座る（途中まで）」と「座る（最後まで）」の両方で突き抜ける所は 2 か所）。おすすめの直し方の数を足すと、直す範囲のか所の数になります
- ポーズは、**今の姿勢（編集の姿勢）を基準**にして付けます。今の姿勢ですでに突き抜けている所は数えません（それは「貫通を直す」（12 章）の受け持ちです）
- 数えるのは、布が体の中に入っている所と、体の尖った所が布の外へ出ている所です。**許容の深さ**（既定 1mm）より浅いものは数えません
- 体の部品どうしが重なる所（腕を下ろすと手が太ももに入る、など）は、服では直せないので、貫通としては数えず「**体どうしの重なり**」として分けて出します（13-6）
- くわしく表示で、手持ちの AnimationClip（座りモーション・ダンスなど）のポーズも試せます（13-7）
- 服の形は、今の編集の形（保存していない分も含む）で調べます。形を変えたり保存したりすると「**形が変わりました。もう一度チェックしてください**」と出ます

### 13-3. 見る・直す範囲・おすすめの直し方
**直す範囲（大きく動くポーズも直す）**: ポーズは全部試しますが、**色分けの点・悪い順の上位・外へ逃がす・ウェイトを体に寄せる**は、既定では**よく使うポーズの結果だけ**で決めます。
大きく動くポーズでスカートなどが太ももに抜かれるのは普通で、全部を直そうとすると、服が大きく膨らんだり、脚に貼り付いて伸びたりするためです（VRChat では揺れもの（PhysBone）で動かすことが多いです）。
- 「**大きく動くポーズも直す**」（かんたん表示にも出ます。既定はオフ）をオンにすると、大きく動くポーズも入れて、これらを作り直します。保存してある各ポーズの結果から作るので、**チェックのやり直しは要りません**（すぐ切り替わります）
- 外へ逃がしたあとの調べ直しで「効いたか」を決めるときも、同じ範囲のポーズで比べます（範囲の外のポーズが少し変わっても、戻しません）
- 設定は、次に開いたときも残ります

**見る**:
- 悪い順の上位 3 つ（直す範囲のポーズ）が出ます。大きく動くポーズを直さないときは、「**大きく動くポーズ（直す範囲の外）**」の小さな見出しの下に、その上位 2 つも出ます
- 上位の行を押す、または「**順に見る**」を押すと、そのポーズをシーンで見せます（順に見るは、上の一覧の順。直す範囲のポーズが先）。元のアバターは隠れ、複製がそのポーズになり、突き抜けた所に**白い縁の赤い点**が出ます（体どうしの重なりの所は**紫の点**）。座る・しゃがむでは、足が床に付くように体全体が下がります
- 「**順に再生**」で、試したポーズを 1 つ約 1 秒ずつ見せます
- 「**元の姿勢に戻る**」を押すか、シーンビューをクリック・Esc、ほかの操作（つまむ・Undo・編集の終了など）をすると、編集の姿勢に戻ります
- 「**突き抜ける所を色の点で示す**」: 直す範囲のポーズで一番深く突き抜けた深さで、編集の姿勢の服に点を出します（黄 1mm → 赤 1cm 以上）。ふだんの編集の画面で、どこを直せばよいかが分かります。結果が出たときに出し、**ほかの操作（ブラシ・選ぶ・ハンドル・ピン留め・Undo など）を始めたとき**と、**形が変わって結果が古くなったとき**に消えます。このトグルで、いつでも出し直せます（結果が出たときに出すかは、くわしく表示の「結果が出たら色の点を出す」で決めます）
- くわしく表示では、試すポーズの選択（よく使う・大きく動くに分けて）、2 段階で試すか、許容の深さ、ポーズごとの結果（「見る」でそのポーズ。大きく動くポーズには［大］）、外へ逃がせる所の内訳が出ます

**おすすめの直し方**: 結果の下に、件数つきで次の順に出します（数は、直す範囲のポーズで数えます）。
1. 「**浅い所が N か所**」→［**元のポーズで外へ逃がす**］（13-4）
2. 「**ウェイトが原因の所が N か所**」→［**ウェイトを体に寄せる**］（13-5）
3. 「**体どうしの重なり N か所: 服では直せません（気にしなくて大丈夫です）**」（13-6）

- 直す範囲に突き抜けが無ければ「直すことはありません ✓」と出ます（大きく動くポーズだけに突き抜けがあるときは、直したいときの方法も一言出ます）
- 外へ逃がしても効かずに戻したあとは、外へ逃がすを勧めず、「浅い所 N か所は、外へ逃がしても減らなかったので、このままで大丈夫です」と出し、ウェイトが原因の所があれば、そちらを勧めます
- 長い説明（か所の数え方・浅い所・ウェイトが原因の所・体どうしの重なり・大きく動くポーズ）は「**くわしい説明**」の折りたたみにあります
- 例（テスト用のアバター、既定の範囲）: スカートは「ウェイトが原因の所 9 か所・体どうしの重なり 17 か所」、タイツは「ウェイトが原因の所 1 か所・体どうしの重なり 4 か所」、袖は「ウェイトが原因の所 8 か所・体どうしの重なり 19 か所」

### 13-4. 元のポーズで外へ逃がす（修正の第 1 段）
おすすめの直し方の「**元のポーズで外へ逃がす**」を押すと、直す範囲のポーズで見つかった浅い所の布を、編集の姿勢で外へ動かします。
- 動かす量は、そのポーズで足りる量です（深さ＋2mm を、「編集の姿勢で外へ動かした分が、そのポーズでどれだけ残るか」の割合で割ったもの。割合は、少し外へ動かした服を同じポーズで取り出して測ります）
- 周りの布は、布の長さを保って面に沿って付いてきます。今の位置より内へは入りません（ほかの所が別のポーズで新しく突き抜けないように）
- 布に余裕が無い所（ぴったりの服）は、布が 3% より伸びる・しわが寄る手前で止めます
- 終わったら自動でもう一度チェックし、窓の結果の欄に「前回の外へ逃がす: すべてのポーズの突き抜け 29 → 25 か所（逃がした所の深さの平均 2.9 → 0.0 mm）」のように前後を出します（窓の真ん中の通知は「外へ逃がしました」の一言だけ）
- 逃がした所が十分浅くならない（深さの平均が 6 割以下にならない）か、直す範囲のポーズの突き抜けが減らないときは、**自動で逃がす前の形に戻し**ます（通知は「元に戻しました（効果なし）」。そのあとは外へ逃がすを勧めません）
- 気に入らなければ、**Ctrl+Z の 1 回**で逃がす前に戻ります
- 周りの布に、わずかなしわ（陰影の筋）が出ることがあります。気になるときは Ctrl+Z で戻してください

**ウェイトが原因の貫通は、この修正では直りません。** 次の所は、動かさずに残します（おすすめの直し方では「ウェイトが原因の所」に数えます。くわしく表示の内訳に「逃がせない所 N か所（関節を深く曲げた所 N、外へ逃がすには深すぎる所 N、体にぴったりで余裕が無い所 N）」と出ます）。
- 編集の姿勢で動かしても、ポーズではほとんど離れない所（ひざ・ひじを深く曲げたときなど。服と体で、関節のウェイトの混ざり方が違うため）
- 2cm より多く動かさないと足りない所（ゆったりしたスカートが、座ったときに太ももに抜かれる、など。スカートが太ももに付いていかないため）
- 体にぴったりで、布に余裕の無い所（タイツ・スカートの腰回りなど。体まで 1.5cm 以内の頂点が半分以上の所）。外へ出すと周りの布が引かれてずれ、別のポーズでかえって深くなることがあるため

これらは、服のウェイトを直す必要があります。次の「ウェイトを体に寄せる」（13-5）で直せます。

### 13-5. ウェイトを体に寄せる（修正の第 2 段）
ウェイト（服と体のボーンの割り振り）が原因の貫通は、その所の服の頂点に、近くの体のウェイトを写して直します。
直す範囲のポーズにウェイトが原因の所があるときだけ、おすすめの直し方に「**ウェイトを体に寄せる**」が出ます（くわしく表示では、その下の「ウェイトを体に寄せる」の欄にも、確認・適用などのボタンが出ます）。

1. 「**ウェイトを体に寄せる**」を押す
2. 候補のウェイトで同じポーズをもう一度試して（シーンもアセットも、まだ変えません）、前後を出します。数は直す範囲のポーズで数えます。例（テスト用のアバターのタイツ、大きく動くポーズも直す範囲）:
   「ウェイトを変える頂点: 738 / すべてのポーズの突き抜け: 5 → 4 ポーズ、31 → 13 か所、いちばん深い所 12.9 → 2.6 mm / ウェイトが原因の所: 31 → 13 か所 / 体から離れた所の布の伸び: 増えません」
3. よければ「**適用**」を押す。**Ctrl+Z の 1 回**で戻せます（窓の真ん中の通知は「ウェイトを体に寄せました」の一言。前後の数は窓の結果の欄に残ります）。確認のダイアログでやめたときは、窓に出る「この候補を適用」で、あとから適用できます

- 既定の範囲（よく使うポーズだけ）のテスト用のアバターでは、スカートのウェイトが原因の所が 9 → 2 か所、タイツが 1 → 0 か所、袖が 8 → 2 か所になります

- **対象**: 動作チェックでウェイトが原因と分かった所（関節を深く曲げた所、外へ逃がすには深すぎる所、体にぴったりで外へ逃がす余裕の無い所）と、その周り。体どうしの重なり（13-6）は対象にしません
- **写し方**: 服の頂点ごとに、編集の姿勢で一番近い体の表面の点を探し、その点のウェイトを、体の三角形の 3 頂点のウェイトから補って写します。体のボーンは服の同じボーンに置き換えます（服が別のアーマチュアなら、名前と位置で対応するボーン）。服のレンダラーに無いボーン（スカートに無い脚のボーンなど）は、レンダラーのボーンの末尾に足します。対応するボーンが無ければ、一番近い親のボーンにします
- **強さ**（既定 100%）: 元のウェイトと体のウェイトを混ぜる割合です。寄せる所から周りへ、**周りへの広がり**（既定 3cm、布に沿って測る）でなめらかに減らします。体から 1.5cm より離れた布は、離れるほど混ぜる割合を減らします（8cm で 0。ゆったりしたスカートを脚に貼り付けないため）
- 1 頂点に付けるボーンの数は、レンダラーの Quality（Auto なら Project Settings の Skin Weights）に合わせ、多すぎる分は小さいものから外します。ウェイトの合計は 1 にそろえます
- **体から離れた所の布の伸び**: 確認の前後に、スカートなど体から離れた所の布が、ポーズでどれだけ伸びるか（伸びの大きいほうから 1% の辺）を、一番増えたポーズで比べて出します。20% 分より増えると「脚などに貼り付いて伸びます」と出るので、くわしく表示で強さを下げてください（テスト用のスカートでは、強さ 100% でしゃがむときの伸びが 54% → 155%、50% なら 54% → 65%）。タイツや袖のように体にぴったりの所は、体と一緒に伸びてよいので入れません
- ゆったりしたスカートが座ったときに太ももに抜かれる所のうち、裾のように体から離れた所は、脚に貼り付けないため直りません（か所と深さの合計は減ります）。形を「つまむ」で整えるか、PhysBone などで動くようにしてください

**適用すると**、次の 2 つを Unity の Undo の 1 段で行います。
- 衣装のシェイプキーのデータ（8 章。無ければ作ります）に、**ボーンウェイトの変更**として、変えた頂点だけを記録します。ボーンは名前とアバターのルートからの道のりで持つので、メッシュを差し替えても当て直せます。シェイプキーの一覧の「**メッシュに反映**」とアップロード時の自動適用（8-7）では、元のメッシュに BlendShape を入れるときに、この変更も当て、足したボーンもレンダラーに付けます。前に記録した変更があれば合わせます（同じ頂点は新しいほう）
- 今の編集のメッシュのウェイトを変えて、編集を作り直します。元のメッシュは書き換えず、複製を保存先のフォルダに作って差し替えます（GP02 が作ったメッシュなら、そのまま書き換えます）。確認で試した結果が、そのまま今の結果になります
- 保存していない編集があるときは、先に保存するかを聞きます（「保存しないで続ける」を選ぶと、保存していない形は戻ります）

くわしく表示では、強さ・周りへの広がり・確認（試す）・適用・候補を捨てるのほか、「**データから外す**」が使えます。記録したウェイトの変更を外し、衣装のメッシュのウェイトを元のメッシュのものに戻します（足したボーンも外します。Ctrl+Z で戻せます）。

### 13-6. 体どうしの重なり
ポーズによっては、体の部品どうしが重なります（腕を下ろすと手が太ももに入る、ひじを深く曲げると内側で腕が入り込む、お辞儀でおなかが折れ込む、など）。
そこは、服がどれだけ体にぴったり付いていっても体の中に入るので、**服では直せません**。
- 次の所を「体どうしの重なり」として分けます。布が体にぴったり付いていっても（編集の姿勢で一番近い体の点に付いていっても）、そのポーズで体の中に入る所。布の外へ出た体の頂点が、ほかの体の部品の中にある所
- 編集の姿勢で服に覆われていなかった体の部品（服の外にある手など）が、ポーズで布の外に並んだだけの所は、数えません
- おすすめの直し方に、突き抜けとは分けて「体どうしの重なり N か所: 服では直せません（気にしなくて大丈夫です）」と出し、ポーズを見ると**紫の点**で示します。ポーズごとの行は「突き抜けなし（体どうしの重なり 2 か所）」のようになります
- 貫通の数・外へ逃がす・ウェイトを体に寄せるの、どれにも入れません

### 13-7. 手持ちの AnimationClip で試す（くわしく表示）
「動作チェック」の「**手持ちの AnimationClip**」に、座りモーションやダンスなどのクリップを足すと、プリセットのポーズに加えて、クリップから取り出したポーズも試します。
- **取り出す間隔**（既定 8 コマ。クリップのフレームレートで数える）ごとに、最後のコマも入れて取り出します。1 つのクリップは最大 60 コマです（長いクリップは間隔を広げます）
- 結果には「Sit 0.5秒」のように、クリップの名前と時刻で出ます。「見る」でそのコマのポーズを見せられます。クリップのコマは、よく使うポーズとして数えます
- **Humanoid のクリップ**（筋肉のカーブのもの）は、どのアバターでも使えます。**Generic のクリップ**は、ボーンのパス（アバターのルートからの道のり）がこのアバターに合うときだけ使います。合わないときは「使いません」、一部だけ合うときは「N 個のうち M 個が合うので、その分だけ動かします」と出ます
- プリセットのポーズを全部外して、クリップだけで試すこともできます。足したクリップ（アセットのもの）と間隔は、次に開いたときも残ります

### 13-8. 時間の目安
- 動作チェック・外へ逃がす・ウェイトを体に寄せるの窓の真ん中の通知は、短い一言だけです（「外へ逃がしました」「元に戻しました（効果なし）」「ウェイトを体に寄せました」など）。前後の数などの詳しい結果は、窓の「動作チェック」の結果の欄に残ります
- テスト用のアバター（服の頂点 約 4,000、体の三角形 約 25,000）で、15 ポーズ × 2 段階が約 5 秒です（Burst あり）。調べている間も Unity は固まりません（ほかの操作をすると、調べるのをやめます）
- 「ウェイトを体に寄せる」の確認は、同じポーズをもう一度試すので、動作チェック 1 回分くらいかかります（テスト用のタイツで約 6 秒）。この間は進み具合を出して、Unity は待ちます
- 手持ちの AnimationClip を足すと、取り出したコマの数だけ時間が増えます（1 コマはプリセットのポーズ 1 つと同じくらい）
