# GP02 Cloth Edit Manual

GP02 is a mesh editing tool for Unity: **grab clothing and pull it**, and the cloth settles into a natural shape.
The cloth is simulated as particles at 1 cm spacing, so **pulling does not stretch the cloth, and it does not pass through the body or inner layers**.
The result is saved as a **shape key (BlendShape)**.

The Japanese manual is `20261011_使い方.md`. The "Manual" button at the top of the window opens the one that matches the interface language.

## 1. Installation

### Requirements
- Unity 2022.3 or later (tested with 2022.3.22f1)
- The VRChat SDK and NDMF are **not required**. Every feature works in plain Unity

### Install from the .unitypackage sold on BOOTH
1. Open your avatar project in Unity
2. Drag the downloaded `.unitypackage` into the Project window (or use **Assets > Import Package > Custom Package**)
3. Make sure every item in the list is checked and press "Import"
4. If the Console shows no red errors, you are done. **Tools > GP02** appears in the menu

### Make it faster (optional)
With **Burst** (Unity's acceleration package) installed, large clothing stays smooth.
Press **Install Burst** in the cloth edit window (shown only when Burst is missing), or install "Burst" (`com.unity.burst`) from the Package Manager. Every feature works without it, but with layered or large clothing the settling after you release may time out and leave stretch, so installing it is recommended.
If the "Acceleration" row of the edit window says "Burst (enabled)", it is working.

### About this manual
This manual lives in the package's `Documentation~` folder. Folders ending in `~` are not imported by Unity,
so if you installed via .unitypackage, open the file directly from the `Documentation~` folder of the distribution.

## 2. Your first edit (with the test clothing)

Try everything once with the bundled test clothing.

### 2-1. Create the test clothing
Menu **Tools > GP02 > テスト用の衣装を作る** ("Create test clothing". The menu items are in Japanese)
- `GP02_TestCloth` appears in the scene with the skirt selected
- It is a simple rigged body (1.4 m tall) and a skirt with a petticoat and a ribbon

### 2-2. Start editing
1. Menu **Tools > GP02 > 布の編集** ("Cloth Edit") opens the window
2. "Set from Selection" then "Start Editing"
3. Preparation takes a few seconds. A hint appears at the top left of the Scene view and the GP02 tool bar appears on the right

The top of the window shows a five-step guide with marks for how far you have come.

| Step | What to do |
|---|---|
| 1. Choose the clothing | Select the clothing object in the Hierarchy, then "Set from Selection" |
| 2. Start editing | Press "Start Editing" |
| 3. Pin what should not move (optional) | Press **P** and paint the waist, for example |
| 4. Grab and pull | Press **W** and drag the cloth |
| 5. Save as a shape key | In the Save section enter a name and press "Save as Shape Key" |

### 2-3. Pin, grab, save
1. Hover the Scene view, press **P** and paint around the waist. Red dots appear (this area will not move)
2. Press **W**, grab the hem of the skirt and pull it outward. When you release, the cloth settles for a moment and stops
3. Press **Ctrl+Z** if you do not like it
4. In the Save section of the window, enter a name and press "Save as Shape Key"
5. A mesh is created in `Assets/GP02/Meshes/` and the skirt gets a new shape key (weight 100). Move the weight from 0 to 100 in the Inspector to blend between the original and edited shapes

You can keep editing after saving. Saving again adds a second shape key.

### 2-4. When you are done
Press "End Editing". You may delete the test clothing from the scene.

## 3. Tools and shortcuts

Press the keys while the mouse is over the Scene view. While you hold the right mouse button to fly around (W/E and so on), or while you are not editing, Unity's own behavior is left alone.

### Tools
| Tool | Key | How to use |
|---|---|---|
| Grab | **W** | Drag the cloth to pull it. The cloth around follows without stretching |
| Rotate | **E** | Click the cloth and drag sideways. It rotates around the clicked point (**Ctrl** for 15-degree steps) |
| Scale | **R** | Click the cloth and drag sideways. Scales 0.2x to 3x around the clicked point |
| Pin | **P** | Paint to fix an area |
| Unpin | **Shift+P** | Paint to remove pins |
| Restore Brush | **T** | Paint to bring an area back toward its original shape (strength is a brush setting) |
| Select & Move | **Q** | Paint to select points, then move / rotate / scale them with a handle. Press **Q** again for the previous tool. See "7. Select & Move" |

While Select & Move is active, **W / E / R** switch the **handle type** (move, rotate, scale) instead of the tool. P, Shift+P and T always switch tools.

### Other keys
| Operation | What it does |
|---|---|
| **Shift**+Drag | Moves at 1/5 speed (fine control) |
| **Ctrl**+Wheel, `[` `]` | Brush radius |
| **Ctrl+Shift**+Wheel, **Shift**+`[` `]` | Influence range |
| **C** (hold) | Show the original shape |
| **Esc** | Cancel the stroke being dragged or settled (when idle, clears the selected points) |
| **Ctrl+Z** / **Ctrl+Y** | Undo / redo one operation at a time |
| **Alt**+Drag | Orbit the view |
| **F1** | Show / hide the shortcut list |
| **Shift**+Drag with Pin / Unpin | Pin / unpin everything inside a rectangle |
| **Ctrl**+Click with Pin / Unpin | Pin / unpin the whole part (island) under the cursor |
| Drag / **Ctrl**+Drag with Select & Move | Paint to select / paint to deselect |
| **Shift**+Drag / **Ctrl+Shift**+Drag with Select & Move | Select / deselect inside a rectangle |
| Double-click with Select & Move | Select the whole part (island) (**Ctrl** to deselect) |
| Click on empty space with Select & Move | Clear the selection |
| Drag the handle with Select & Move | Move the selected points (**Shift** slow, **Ctrl** snap) |

### The Scene view tool bar
While editing, a "GP02" tool bar appears on the right of the Scene view.
- The top six buttons and "Select & Move" switch tools (the same as "Tools" in the window). While Select & Move is active, the handle type (Move, Rotate, Scale) buttons appear as well
- "Symmetry", "Stretch" and "Original" are on / off switches
- "Shortcuts" shows or hides the list, and "Manual" opens this document

It changes the same settings as the window, so changing it in either place is equivalent.

### The top of the window
"Language" switches between Japanese and English. "Manual" opens this document and "?" shows the shortcut list.
Hover any button or slider to see its tooltip.

## 4. Brush settings

Set these in the "Brush" section of the window.

| Setting | Meaning |
|---|---|
| Brush Radius (cm) | Radius of the grabbed area. Also **Ctrl+Wheel** or `[` `]` |
| Influence (cm) | How far the grabbed motion spreads. Also **Ctrl+Shift+Wheel** or **Shift**+`[` `]` |
| Falloff | How the motion weakens from the center to the edge. Presets (Constant, Smooth, Linear, Sharp, Sphere) or draw your own |
| Distance | "Along the surface" uses only connected cloth; "Straight line" takes anything nearby regardless of layer (to move inner layers together) |
| Restore Brush Strength | How far each stroke brings the cloth back to its original shape (1 restores it fully) |

The "Tools" section also lets you choose the **move direction** for Grab (free, surface normal, X / Y / Z axis) and the **rotation axis** for Rotate (view direction, surface normal).

### The preview before you apply the brush
Hover the cloth and the particles in range appear as dots. **They are yellow and opaque near the center and blue and faint near the edge** (the weight).
While you drag, the particles of the grabbed area keep the same colors. With symmetry on, the mirrored side shows too.
If there are many, the dots are thinned out (at most 1500). Turn it off with "Show Brush Range" in the Display section.

### Seeing stretch and comparing with the original
- "Stretch Heatmap" shows each particle's stretch as green / yellow / red dots (0% / 5% / 15%). "Max Stretch" in the window shows the number
- "Show Original Shape" or the **C** key shows the shape before editing. The "Blend (%)" slider shows anything between the original and the edited shape

## 5. Symmetry

Turn on "Symmetric Editing" in the Symmetry section, and grab / rotate / scale / pin / restore **also act on the opposite side, mirrored**.

- **Axis**: the axis perpendicular to the mirror plane (X for left / right), in the avatar's local space
- **Center Offset**: the offset of the mirror plane from the avatar's center (cm)
- **Reference**: the parent with an Animator (the avatar). If none is found, the topmost parent is used

Conditions:
- The clothing must be **left-right symmetric about the avatar's center** (if no matching particle is found on the other side, only one side moves)
- Near the center line, motion is limited to the directions along the mirror plane so the two sides do not drift apart

The Scene view shows the mirror plane as a translucent rectangle, and the brush circle is also shown on the mirrored side.

## 6. Pins (fix what should not move)

Pinned areas stay put while you pull elsewhere. It helps to pin the waist and the like first.

### Painting
With **P** (Pin) / **Shift+P** (Unpin), drag to paint. The painted size is the brush radius.

### A rectangle at once (Shift+Drag)
With Pin or Unpin, **hold Shift and drag** to draw a rectangle on the screen. When you release, everything inside is pinned (unpinned) at once.
- By default only **particles facing the camera (the front side)** are used. To include the back side, turn off "Rectangle: front only" in the Tools section
- Occlusion is not checked (overlapping cloth is included if it falls inside the rectangle)
- With symmetry on, the opposite side is treated the same way
- A rectangle smaller than 4 pixels does nothing. Esc cancels

### A whole part (Ctrl+Click)
With Pin or Unpin, **hold Ctrl and click** to pin (unpin) the **whole connected piece of cloth (island)** under the cursor.
Handy for fixing an entire petticoat, for example.

### Clear all and invert
Buttons in the Tools section (while editing).
- **Clear All Pins**: removes every pin
- **Invert Pins**: unpins what was pinned and pins what was not (useful to move only one area by pinning everything else)

Each one is undone in one step with **Ctrl+Z**.

## 7. Select & Move (select points, then move them with a handle)

Instead of "grabbing" the cloth, this tool lets you **select points and move, rotate or scale them with a handle**. It is the counterpart of EreMorph's "select vertices and move them with the handle".
Use it when you want to **decide the amount of motion yourself**: "lower exactly this part by 3 cm", "rotate this area by exactly this angle", "make the hem longer".

You can specify things more finely than with Grab, because you see the points you move. Pins, Ctrl+Z and saving as a shape key work just like with the other tools.

### 7-1. What a point is
- Points are **particles laid out on the surface of the cloth at 1 cm intervals** (they are separate from the mesh vertices)
- The mesh **vertices follow the nearby points**. Even a coarse clothing mesh can be selected and moved at a 1 cm resolution
- The number of points is shown as "Particles" in the window

### 7-2. Selecting
Press **Q** or choose "Select & Move" in the tools (press **Q** again to return to the previous tool).

| Operation | What it does |
|---|---|
| Drag (a click too) | **Paint to select** with the brush radius (adds). Radius: **Ctrl+Wheel** or `[` `]` |
| **Ctrl**+Drag | Paint to **deselect** |
| **Shift**+Drag | Select inside a **rectangle** (adds). You can start where there is no cloth |
| **Ctrl+Shift**+Drag | Deselect inside a rectangle |
| **Double-click** | Selects the **whole part (a connected piece of cloth = island)** under the cursor (**Ctrl** to deselect) |
| Click on empty space | **Clear** the selection |
| **Esc** | Cancels the operation in progress. When idle, clears the selection |

- A double-click selects the whole part, including the area the first click just painted
- Under the mouse, the points that painting would select (within the brush radius, in the same part) are shown in **light pink**. The brush circle is pink, too
- Selected points are **orange**. When there are many, only some are drawn (the computation uses all of them)
- A rectangle selects **only the points visible on screen** by default (not points hidden behind other cloth or on the back side). To select hidden points too, turn on "Select Hidden Points" in the Selection section
- The selection is not undone by Ctrl+Z (the shape and pins are undone, the selection stays). Press **Esc** or "Clear" to select again

### 7-3. Moving with the handle
Once points are selected, a **handle** appears. Drag it to move them.

| Key | Handle |
|---|---|
| **W** | Move |
| **E** | Rotate |
| **R** | Scale (per axis, too) |

- While Select & Move is active, W/E/R switch the **handle type** (the tool stays Select & Move). **P**, **Shift+P** and **T** still switch tools as before
- Hold **Shift** while dragging for slow motion (1/5)
- Hold **Ctrl** while dragging to use Unity's standard snapping
- **Esc** during a drag returns to the state before you pressed. On release the surrounding cloth settles, and **Ctrl+Z** undoes it in one step
- A click on the handle goes to the handle (it does not start painting a selection)
- **Pinned points do not move even if selected**. The window shows a notice
- The number of selected points is shown next to the handle

### 7-4. Pivot and orientation
Set them in the Selection section of the window.

| Setting | What it does |
|---|---|
| Pivot | The center of rotation and scaling, and where the handle appears. **Selection center** (the average of the current positions) / **Clicked point** (the point on the surface you clicked last) |
| Orientation | The axes of the handle. **Global** (world axes) / **Avatar** (the avatar's orientation) / **Surface normal** (Z is the normal of the surface of the selected points) |

While you drag, the handle stays at the position and orientation where you pressed it.

### 7-5. Move Style (As cloth / Shape only)
Switch it with "Move Style" in the Selection section.

| | As cloth (default) | Shape only |
|---|---|---|
| Motion | Moving the selected points makes **the surrounding cloth follow through the cloth simulation**, without stretching | The selected points and the smooth range move **exactly as specified** |
| Cloth length | Kept. **Points stop short where the cloth cannot reach** | Not kept. **The cloth may stretch** |
| Settling | After release, it computes until the surrounding cloth settles | No simulation, so it is fixed on the spot at release |
| Good for | Changing the shape naturally: spreading the hem outward, gathering folds, shifting | **Edits that change the cloth's length**: making the hem longer or shorter, changing the width or length |

Rule of thumb:
- Try **As cloth** first. It gives a natural shape without stretching
- If the amount you want is large and the points stop short (the cloth cannot reach), switch to **Shape only**. For example, **making the hem longer** changes the cloth's length, so do it with "Shape only"
- After moving with "Shape only", check the stretch with the "Stretch Heatmap" in Display if it worries you

### 7-6. Smoothness
"Smoothness Radius (cm)" (0 to 30) in the Selection section is the **range where the motion fades out smoothly** from the edge of the selected points.
- With 0, only the selected points move (the surrounding cloth still follows through the simulation)
- Larger values move the area around the selected points together, so the border is less noticeable
- "Falloff" chooses how it fades (Constant, Smooth, Linear, Sharp, Sphere, Custom). It is a **separate setting from the brush Falloff** (only "Custom" uses the curve drawn for the brush)
- With "Show Range Colors" on, the points of the smooth range are colored by how strongly they move (strong is yellow, weak is blue). While you move, the range being moved is shown in the same colors

### 7-7. Selection operations (buttons)
Buttons in the Selection section.

| Button | What it does |
|---|---|
| Select All / Clear / Invert | Select everything / deselect everything / swap the selected and unselected points |
| Grow / Shrink | Add one ring around the selection / remove the outer ring (within the same part) |
| Select Mirror Side | Also selects the mirrored points on the opposite side. The mirror plane comes from the axis and offset in Symmetry (works even with symmetry off) |
| Pin Selection | Pins the selected points (Ctrl+Z undoes it) |
| Select Pinned | Adds the pinned points to the selection |

### 7-8. Move by Numbers
Open "Move by Numbers" in the Selection section to move by numeric values.
- Enter **Move (cm)**, **Rotate (deg)** and **Scale (%)** per X/Y/Z axis and press "Apply" (100% means no change)
- The axes are those of **the handle's current orientation** (Global / Avatar / Surface normal). The pivot of rotation and scale follows the Pivot setting
- The result is the same as moving the handle to the same values, and **one Apply is one Ctrl+Z step**
- "Reset Values" returns the fields to move 0, rotate 0, scale 100%

### 7-9. Symmetry
With symmetric editing on, **the opposite side moves mirrored automatically**, so you do not need to select it (the window says so, too). The points that move on the opposite side are shown in light orange.
If the selection crosses the center line, the motion is limited to the part along the mirror plane.

### 7-10. Shortcuts (Select & Move)
| Key / operation | What it does |
|---|---|
| **Q** | Switch to Select & Move. Press again for the previous tool |
| **W** / **E** / **R** | Switch the handle to Move / Rotate / Scale |
| Drag / **Ctrl**+Drag | Paint to select / paint to deselect |
| **Shift**+Drag / **Ctrl+Shift**+Drag | Select / deselect with a rectangle |
| Double-click (**Ctrl** to deselect) | Select (deselect) the whole part |
| Click on empty space | Clear the selection |
| Drag the handle (**Shift** slow, **Ctrl** snap) | Move the selected points |
| **Esc** | Cancel the operation; when idle, clear the selection |

## 8. Saving and the shape key list

### 8-1. Save as a shape key
Enter a name in the Save section and press "Save as Shape Key":
- It is added as a shape key (BlendShape) to a copy of the original mesh (`Assets/GP02/Meshes/`)
- The edit is also recorded in the **data** (`Assets/GP02/Data/`). Pins are kept too, so you can **re-edit later**
- **Ctrl+Z** undoes the save

Saving fails if the mesh already has a shape key with that name. Choose another name.

### 8-2. The shape key list
Open it from the menu **Tools > GP02 > シェイプキーの一覧** ("Shape Key List") or from the Inspector of the `GP02 Shape Keys` component on the clothing.
Use it to check and process saved shape keys.

- **Weight sliders**: preview on the scene mesh (the preview is undone when you close the window or select something else)
- **Edit with cloth** (right-click): continue editing a saved shape key as cloth. Return with "Save (overwrite)" or "Save as new"
- **Duplicate, copy, paste, delete**: you can paste into another data asset if the vertex counts match
- **Groups, enable / disable, reordering**: drag to reorder and gather into groups. Disabled ones are not exported
- **Merge**: adds the selection into one with the slider weights
- **Split L/R**: splits into `_L` and `_R` (adding them gives back the original). The blend width at the center is set in "Operation settings"
- **Flip / Symmetrize**: copies to the opposite side. The axis, center and mirror search distance are in "Operation settings"
- **Scale**: multiplies the amount (150% gives 1.5x)
- **Chain into in-between**: lines the selection up into one shape key with in-between frames. Crossfade or Progressive
- **Recompute normals**: see 8-4

### 8-3. Import
The "Import" section brings existing shape keys into the list so you can process them or re-edit them as cloth.
- **From the source mesh's BlendShapes**: the BlendShapes stored in the mesh (all, or one)
- **From another mesh**: imports the difference from that mesh (same vertex count)
- **From AnimationClip**: imports the BlendShape values at a chosen time

### 8-4. Recompute normals
A shape key stores **normal deltas** as well as position deltas. Wrong normals make the shading look off when it moves
(only the UV seams look different, or an imported shape key shades strangely). In that case select the shape keys and press
"**Recompute normals**" under "Operations on the selection" (also in the right-click menu).
It works on shape keys imported from existing BlendShapes too, and Ctrl+Z undoes it.

"Operation settings" has two options:
- **Normal smooth angle (deg)**: faces of vertices at the same position are joined smoothly if their angle is within this value. **180 (default) joins everything.** Lower it to keep hard edges (for example 60). The angle is judged on the original shape
- **Normals: merge vertices at the same position**: aligns the normals of vertices split at UV seams and the like. If off, each vertex uses only its own faces (the smooth angle has no effect then)

### 8-5. Export
The "Export" section of the list.
- **Export to mesh**: adds the enabled shape keys as BlendShapes to a copy of the source mesh, saves it and assigns it to the renderer. The data is kept. With "Overwrite same names" off, a same name becomes "name (1)"
- **Bake the selection into the base**: bakes the selected shape keys into the base shape with the slider weights as a new mesh. "Remap bone weights of far-moved vertices" gives far-moved vertices the bone weights of the vertex they moved to (avoids leftover hand weights after shortening a hem, for example)
- **Restore the original mesh**: puts the renderer's original mesh back

Even if you delete the data asset, the exported mesh remains as an asset. Removing the tool does not delete the mesh.

### 8-6. Editing layered clothing together
Layered clothing, such as a petticoat inside a skirt, can be edited together as one cloth. Pushing the outer layer inward also pushes the inner layer, and the outer layer never passes through it.
1. Set the outer cloth as the "Target" in the window
2. Press "Add Layers of the Same Avatar" (meshes of the same avatar whose surfaces are close to the target are added). To pick them by hand, select them in the Hierarchy and press "Add Selection"
3. Press "Start Editing". Grabbing, pins and saving work on all layers together
4. Saving adds a shape key with the same name to each mesh. Ctrl+Z undoes them all at once

- If one mesh contains several layers (for example, a lining in the same mesh), the layers are kept apart even without adding anything
- More layers make the calculation heavier. Installing Burst is recommended
- To stop keeping layers apart, turn off "Keep Layers Apart" in the Advanced settings

### 8-7. Applying automatically at upload (NDMF)
In projects with NDMF (the framework used by Modular Avatar and others), shape keys can be added only when the avatar is uploaded (built), without changing the mesh in the scene.
1. In the clothing's "GP02 Shape Keys" component (or the shape key list), set "Apply mode" to **Apply at build (NDMF)**
2. With "Initial weight at build", choose the initial weight of the added shape keys (0, or the slider value in the list)
3. Upload as usual. GP02 runs before Modular Avatar, so Modular Avatar settings can use the shape keys

- The original mesh stays as it is, so conflicts with other mesh editing tools are less likely
- Without NDMF, choosing this setting does not add anything automatically (the window tells you so). Use "Export to mesh" instead
- If you keep a mesh made with "Export to mesh" assigned, set "Apply mode" to **Export to mesh**

## 9. Tuning the Advanced settings

Open "Advanced" in the window to change the simulation values. They are saved automatically, and "Reset to Defaults" (which covers tool, brush, symmetry and display too) restores everything.
Here is **what to change when you notice something**.

| What you notice | Value to change | Direction |
|---|---|---|
| It takes long to settle after releasing | Solve Time per Update (default 12 ms) | Larger (editing gets heavier) |
| Settling is cut short and stretch remains | Settle Timeout (default 2 s) | Longer |
| Settling takes too long to finish | Settle Tolerance (default 1%) | Larger (a bit rougher) |
| The cloth folds too sharply / is too stiff | Bendiness (default 0.1) | Stiffer = smaller, softer = larger |
| The grabbed area lags behind your hand | Grab Softness (default 0.02) | Smaller |
| Stretch remains after a big pull | Grab Softness | Larger (stops short sooner where it cannot reach) |
| The cloth sinks into the body or inner cloth | Stay Outside Original Surface (default on) | Check that it is on |
| You want to push cloth inward on purpose (tucks, etc.) | Stay Outside Original Surface | Off |
| Loose clothing cannot move inward and stretches | Use Gap to Body / Inner Cloth (default on) | Check that it is on |
| Motion does not carry to distant cloth | Coarse Iterations (default 10) | Larger (heavier) |
| The area to pull is too small / too large | Brush Radius (default 3 cm), Influence (default 30 cm) | Sliders near the top of the window |

Also:
- **Stretchiness** (default 0): 0 means the cloth never stretches. Pulling hard lifts the cloth and it stops short
- **Use Accelerated Version**: turn off to compute in plain C# without Burst (for speed comparison)

## 10. Troubleshooting (FAQ)

**Q. Pressing "Start Editing" does not start / a yellow or blue box appears**
A. The text in the box gives the reason and the fix. Common ones:
- The target has no mesh or no triangles: set a SkinnedMeshRenderer (or a MeshRenderer with a MeshFilter) that has a mesh
- **Read/Write is disabled**: the "Enable Read/Write" button in the box fixes it (same as the model's Import Settings)
- Very many vertices: preparation takes a few to ten seconds. Installing Burst speeds up editing

**Q. Pressing W / E / R switches to Unity's own Move / Rotate / Scale tools**
A. Check that the mouse is over the Scene view. While you are not editing, while the right mouse button is held, or while Alt / Command is pressed, Unity's behavior is kept.

**Q. With Select & Move, the selected points do not move / stop partway**
A. Check the following.
- Are the selected points **pinned**? (Pinned points do not move. The window shows a notice)
- Are you moving farther than the cloth can reach? -> Set "Move Style" to **Shape only** and they move as specified (the cloth may stretch)
- When using numbers, did you press "Apply", and is the motion not 0?

**Q. The Select & Move handle does not appear / pressing Q does not switch**
A. The handle appears once points are selected. Hover the Scene view and press Q (while holding the right mouse button, or Alt / Command, Unity's own behavior is left alone).

**Q. The brush circle does not appear**
A. Move the mouse over the cloth (it appears only when it hits the cloth). While Alt is held it is view control.

**Q. The cloth does not follow my hand / stops partway**
A. If you pull beyond the length of the cloth, it stops short without stretching (that is the point). To pull further, lower "Grab Softness" in Advanced or review your pins.

**Q. Stretch remains after a big pull**
A. Pulling tight clothing, or the outer layer of layered clothing, far in a direction it cannot reach can leave stretch. Check with the "Stretch Heatmap", pull less, or raise "Grab Softness".

**Q. The cloth sinks into the body or inner cloth**
A. Check that "Stay Outside Original Surface" is on in Advanced. It does not work on flat parts or on overlapping back faces.

**Q. With symmetry the opposite side does not move**
A. The clothing may not be symmetric about the avatar's center, or the axis / center offset may be off. Look at the mirror plane (translucent rectangle) in the Scene view and fix the axis and center offset in the Symmetry section.

**Q. A thin ribbon or string does not bend well**
A. Parts thinner than 1 cm hold only one or two particles and may not bend well (a known limitation).

**Q. Saving says a shape key with the same name already exists**
A. Use another name. If you started from "Edit with cloth", use "Save (overwrite)".

**Q. I saved, but the shape key is not visible in the Inspector**
A. Saving replaces the SkinnedMeshRenderer's mesh with a copy (its name ends with `_GP02`). Look at that mesh. The original mesh is unchanged.

**Q. The shading looks wrong when I move the shape key**
A. Try "8-4. Recompute normals".

**Q. I want to report an error or something odd**
A. Include the red / yellow Console logs (those starting with `[GP02]`), the "Particles", "Max Stretch", "Acceleration" and "State" rows of the window, and what you did. Please do not send the purchased clothing data itself.

## 11. How GP02 differs from EreMorph and similar tools

GP02 works differently from tools such as EreMorph, where you select vertices and move them.

| | GP02 | Tools where you select vertices and move them |
|---|---|---|
| How you move | **Grab and pull** the cloth. The cloth around follows naturally. "**Select & Move**" also lets you select points and move them with a handle | Select vertices and move them with a handle |
| Cloth length | **Does not stretch** (the simulation keeps the cloth's length). "Shape only" in Select & Move is for edits that change the cloth's length, and it may stretch | Vertices just move, so stretching is easy to miss |
| Clipping | **Does not pass through the body or inner cloth** (stays outside the original surface, and measures the gap automatically) | You fix it by eye |
| Mesh density | Simulated with 1 cm particles, so it **does not depend on vertex density** | Depends on vertex density |
| The scene mesh | **Does not replace the scene mesh.** While editing it only overlays a preview, and it adds shape keys to a copy of the mesh only when you save | Some replace the renderer's mesh, which can conflict with other tools of the same kind |
| Quality check | Visible with the stretch heatmap and the max stretch number | Check by eye |
| Fixing areas | Pins (also by rectangle and by part) | Unselected vertices do not move |
| Use with other tools | Every feature works in plain Unity; no VRChat SDK or NDMF needed | Depends on the tool |

Reproducing fine cloth wrinkles is not a goal (the purpose is to reshape clothing naturally).

VRChat-specific features such as NDMF integration are separate parts. They are enabled only when the target package is installed, and they do not affect the tool itself when it is absent.
